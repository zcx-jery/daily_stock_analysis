## 2. 文档定位

`V1-Aggressive` 不是替代标准版 `V1`，而是同一产品下的另一套风格配置。

该配置面向：

- 偏进攻型的 A 股短线交易者
- 更重视强度、加速、换手和可参与性
- 接受更高波动，换取更高的收益弹性

核心思想：

- 奖励强势
- 奖励分歧转一致
- 奖励可买入的强势股
- 不机械惩罚高位加速
- 只对“弱化的加速”和“致命分歧”做风险扣分

## 3. 版本边界

`V1-Aggressive` 仍然基于 `Tushare 2000分` 可获取数据设计，属于收盘后筛选规则。

### 3.1 能力边界

可以做：

- 收盘后进攻型强势股筛选
- 次日接力候选排序
- 识别“强且买得到”的标的

不能精确做：

- 真实封板时间
- 炸板次数
- 回封速度
- 分时承接强弱

因此，文档中的“封板确定性”在 `V1-Aggressive` 中依然是 **日线代理口径**，不是盘口级真实判定。

## 4. 候选池硬过滤规则

与标准版 `V1` 保持一致。

推荐默认值：

- `min_change_pct = 7`
- `min_amount = 3亿`
- `min_turnover = 3%`
- `exclude_st = true`
- `main_board_only = true`

## 5. 评分总结构

### 5.1 基础总分

```text
基础总分
= 强势确认质量(30)
+ 资金承接质量(20)
+ 买入可行性(15)
+ 量价双轨(15)
+ 板块题材共振(12)
+ 趋势位置与弹性(8)
```

### 5.2 最终总分

```text
最终总分 = 基础总分 - 风险修正(0~15)
```

### 5.3 维度分值结构

| 维度 | 分值 | 设计意图 |
|---|---:|---|
| 强势确认质量 | 30 | 重奖强度、收盘地位、加速确认 |
| 资金承接质量 | 20 | 确认是否有真实资金推升 |
| 买入可行性 | 15 | 识别“强且买得到”的标的 |
| 量价双轨 | 15 | 区分缩量一致与健康换手 |
| 板块题材共振 | 12 | 保留主线判断，但不喧宾夺主 |
| 趋势位置与弹性 | 8 | 保留位置判断，但不机械惩罚高位 |
| 风险修正 | 0 ~ -15 | 仅惩罚致命分歧和弱化加速 |

## 6. 强势确认质量 30

目的：用更进攻的方式判断今天是不是“最值得打”的那一批。

### 6.1 涨停/准涨停强度 10

计算口径：

```text
limit_proximity = close / up_limit
```

| 条件 | 分数 |
|---|---:|
| `>= 99.7%` | 10 |
| `99.0% ~ 99.69%` | 8 |
| `98.0% ~ 98.99%` | 6 |
| `97.0% ~ 97.99%` | 4 |
| `< 97.0%` | 0 |

说明：

- 更偏好封死或近乎封死的强势状态
- 相比标准版，大幅提升该项权重

### 6.2 跳空高开强度 8

计算口径：

```text
gap_open_ratio = (open - prev_close) / prev_close
```

| 条件 | 分数 |
|---|---:|
| `3% ~ 7%` | 8 |
| `1.5% ~ 2.99%` | 6 |
| `7.01% ~ 9.5%` | 5 |
| `0 ~ 1.49%` | 3 |
| `< 0` | 0 |

说明：

- 适度跳空高开代表竞价承接强
- 一字式极端高开不自动给满分，因为可参与性在其他维度单独判断

### 6.3 收盘地位 6

计算口径：

```text
close_position = (close - low) / (high - low)
```

特殊规则：

- 若 `high == low` 且收涨，记 `6分`

| 条件 | 分数 |
|---|---:|
| `>= 0.92` | 6 |
| `0.82 ~ 0.91` | 5 |
| `0.70 ~ 0.81` | 3 |
| `0.55 ~ 0.69` | 1 |
| `< 0.55` | 0 |

### 6.4 加速确认 6

计算口径：

- 近 3 日累计涨幅
- 今日收盘强度
- 今日涨停/准涨停状态

| 条件 | 分数 |
|---|---:|
| 近 3 日累计涨幅 `>= 20%` 且今日 `limit_proximity >= 99.0%` | 6 |
| 近 3 日累计涨幅 `15% ~ 19.99%` 且今日强势收盘 | 4 |
| 近 3 日累计涨幅 `10% ~ 14.99%` | 2 |
| 无明显加速 | 0 |

说明：

- `V1-Aggressive` 不再机械惩罚高位加速
- 但高位加速后的风险控制放在风险修正里处理

## 7. 资金承接质量 20

目的：确认涨停或强势上涨背后是否有真实资金。

### 7.1 主力净流入绝对额 8

计算口径：

- 使用 `moneyflow` 中主力净流入金额
- 在候选池内按绝对额排序

| 条件 | 分数 |
|---|---:|
| 前 `10%` | 8 |
| 前 `10% ~ 25%` | 6 |
| 前 `25% ~ 50%` | 4 |
| 后 `50%` 但为正 | 2 |
| 净流出 | 0 |

### 7.2 主力净流入强度 6

计算口径：

```text
main_inflow_ratio = 主力净流入额 / amount
```

| 条件 | 分数 |
|---|---:|
| `>= 6%` | 6 |
| `4% ~ 5.99%` | 5 |
| `2% ~ 3.99%` | 3 |
| `0 ~ 1.99%` | 1 |
| `< 0` | 0 |

### 7.3 价资一致性 4

计算口径：

- 价格强度与资金方向是否一致

| 条件 | 分数 |
|---|---:|
| 涨停/准涨停且净流入明显为正 | 4 |
| 强势上涨且净流入为正 | 3 |
| 强势上涨但净流入偏弱 | 1 |
| 强势上涨且净流出 | 0 |

> 实现说明：V1-Aggressive 代码中简化为两档打分：`pct_chg >= 7% 且主力净流入 > 0` 给 4 分，否则给 0 分。V1.5 可恢复 4 档细化。

### 7.4 龙虎榜质量 2

计算口径：

- 是否上榜
- 是否净买入

| 条件 | 分数 |
|---|---:|
| 上榜且净买入明显为正 | 2 |
| 未上榜或上榜中性 | 1 |
| 上榜且净卖出明显 | 0 |

说明：

- `V1-Aggressive` 仍然不把龙虎榜作为主导因子

## 8. 买入可行性 15

目的：解决“票很强但根本买不进去”的问题。

### 8.1 日内振幅空间 6

计算口径：

```text
amplitude_ratio = (high - low) / close
```

| 条件 | 分数 |
|---|---:|
| `2.5% ~ 6.0%` | 6 |
| `1.5% ~ 2.49%` | 4 |
| `6.01% ~ 8.0%` | 3 |
| `0.8% ~ 1.49%` | 1 |
| `< 0.8%` 或 `> 8.0%` | 0 |

说明：

- 适度振幅说明有换手、有上车机会
- 振幅过低可能是买不到
- 振幅过高则可能是分歧过大

### 8.2 成交额黄金区 5

计算口径：`amount`

| 条件 | 分数 |
|---|---:|
| `5亿 ~ 18亿` | 5 |
| `3亿 ~ 5亿` 或 `18亿 ~ 25亿` | 4 |
| `25亿 ~ 40亿` | 2 |
| `< 3亿` 或 `> 40亿` | 0 |

说明：

- 该项使用绝对值区间，体现“可打性”
- 过小不稳定，过大容易钝化

### 8.3 换手率黄金区 4

计算口径：`turnover_rate`

| 条件 | 分数 |
|---|---:|
| `5% ~ 15%` | 4 |
| `3% ~ 4.99%` 或 `15.01% ~ 20%` | 3 |
| `20.01% ~ 25%` | 1 |
| `< 3%` 或 `> 25%` | 0 |

说明：

- 该项更重视“筹码交换是否充分”

## 9. 量价双轨 15

目的：区分“一致性强板”和“健康换手板”。

### 9.1 缩量一致型 8

适用条件：

- `limit_proximity >= 99.7%`

计算口径：

- `volume_ratio`

| 条件 | 分数 |
|---|---:|
| `< 1.0` | 8 |
| `1.0 ~ 1.49` | 6 |
| `1.5 ~ 2.5` | 3 |
| `> 2.5` | 0 |

说明：

- 这项专门奖励“缩量封死的一致性”
- 但它不代表一定好买，买入可行性由第 8 章单独控制

### 9.2 健康换手型 7

适用条件：

- `limit_proximity < 99.7%` 或者当日存在明显振幅换手

计算口径：

- `volume_ratio`
- `turnover_rate`

| 条件 | 分数 |
|---|---:|
| `volume_ratio 1.5 ~ 3.5` 且 `turnover_rate 5% ~ 15%` | 7 |
| `volume_ratio 1.2 ~ 1.49` 或 `3.51 ~ 4.0` | 5 |
| `volume_ratio 1.0 ~ 1.19` 或 `turnover_rate 3% ~ 4.99%` | 3 |
| `volume_ratio > 5.0` 或 `turnover_rate > 25%` | 0 |

说明：

- 该项奖励“有换手但不爆量”的强势票

## 10. 板块题材共振 12

目的：保留主线识别，但不让它压过个股强度。

数据口径：

- 与标准版 `V1` 保持一致
- 统一使用 **申万一级行业**

### 10.1 板块强度 5

计算口径：

- 所属申万一级行业当日涨幅排名

| 条件 | 分数 |
|---|---:|
| 前 `10%` | 5 |
| 前 `10% ~ 20%` | 4 |
| 前 `20% ~ 35%` | 3 |
| 前 `35% ~ 50%` | 2 |
| 后 `50%` | 0 |

### 10.2 板块联动 4

计算口径：

- 同行业涨停数
- 或 `pct_chg >= 5%` 个股数

| 条件 | 分数 |
|---|---:|
| `>= 3` 只涨停，或 `>= 6` 只大涨 | 4 |
| `2` 只涨停，或 `4~5` 只大涨 | 3 |
| `1` 只涨停，或 `2~3` 只大涨 | 2 |
| 基本孤立 | 0 |

### 10.3 个股板块地位 3

计算口径：

- 在所属行业内按 `pct_chg + amount + close_position` 综合排序

| 条件 | 分数 |
|---|---:|
| 前 `1~2` 名 | 3 |
| 前 `3~5` 名 | 2 |
| 中位或后排 | 0 |

## 11. 趋势位置与弹性 8

目的：保留趋势与空间判断，但不压制强势加速股。

### 11.1 突破结构 4

计算口径：

- `prev_20d_high`
- `prev_60d_high`

| 条件 | 分数 |
|---|---:|
| 突破 `20日高点` 或触及 `60日高点` | 4 |
| 距 `20日高点` 在 `1%` 内 | 3 |
| 距 `20日高点` 在 `3%` 内 | 2 |
| 仍在平台中部 | 0 |

### 11.2 流通市值弹性 2

计算口径：`circ_mv`

| 条件 | 分数 |
|---|---:|
| `30亿 ~ 150亿` | 2 |
| `15亿 ~ 30亿` 或 `150亿 ~ 300亿` | 1 |
| 其余 | 0 |

### 11.3 历史股性 2

计算口径：

- 近 60 日涨停或 `7%+` 大阳线次数

| 条件 | 分数 |
|---|---:|
| 有 `>= 1` 次涨停，或 `>= 3` 次 `7%+` 大阳线 | 2 |
| 有 `1~2` 次明显强势记录 | 1 |
| 无明显历史强势记录 | 0 |

## 12. 风险修正 0 到 -15

目的：只惩罚致命分歧，不机械打压强势股。

### 12.1 价资严重背离

计算口径：

- `pct_chg >= 7%`
- 主力净流入额为负

| 条件 | 扣分 |
|---|---:|
| 涨停/准涨停且净流出明显 | -8 |
| 强势上涨且净流出明显 | -6 |
| 小幅背离 | -3 |
| 无明显背离 | 0 |

### 12.2 爆量滞涨

计算口径：

- `amount / avg(amount_5) >= 3`
- 收盘位置偏低

| 条件 | 扣分 |
|---|---:|
| `>= 3倍` 放量且 `close_position < 0.55` | -5 |
| `2.5 ~ 2.99倍` 放量且收盘一般 | -3 |
| 明显爆量但仍收强 | -1 |
| 无明显问题 | 0 |

### 12.3 长上影 / 冲高回落

计算口径：

```text
upper_shadow_ratio = (high - max(open, close)) / (high - low)
```

| 条件 | 扣分 |
|---|---:|
| `>= 0.35` | -4 |
| `0.25 ~ 0.34` | -2 |
| `< 0.25` | 0 |

### 12.4 板块退潮

计算口径：

- 个股强，但行业联动明显不足

| 条件 | 扣分 |
|---|---:|
| 个股强但板块完全不跟 | -4 |
| 板块弱跟随 | -2 |
| 板块中性或强 | 0 |

## 13. 实战输出建议

`V1-Aggressive` 建议在评分结果外额外输出：

- `buyability_score`
- `entry_range_low`
- `entry_range_high`
- `opportunity_tag`

### 13.1 买入区间建议

建议作为报告层规则，不并入主分。

```text
entry_range_low = max(prev_close * 0.985, prev_open)
entry_range_high = prev_close * 1.015
```

> 实现说明：V1-Aggressive 代码中 `entry_range_low` 仅使用 `prev_close * 0.985`，未加入 `max(prev_open, ...)` 约束。在低开场景下买入区间可能偏低，V1.5 可补齐。

### 13.2 机会标签建议

- `分歧转一致`
- `一致再加速`
- `强更强`
- `高位博弈`

## 14. 当前建议

`V1-Aggressive` 适合作为：

- 第二套评分风格
- 偏短线进攻型用户的可选配置

不建议：

- 用它直接替代标准版 `V1`
- 在没有回测前作为唯一默认规则
