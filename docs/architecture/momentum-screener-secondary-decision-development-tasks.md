## 2. 文档目标

本清单用于把“强势筛选二次决策与执行辅助”继续往下推进一层，形成可执行的研发实施顺序，供前端、后端、接口、测试协同落地。

重点回答四件事：

- 先做什么，后做什么
- 前后端各自要交付什么
- API / Schema 应在什么节点冻结
- 测试怎样跟着实施顺序介入，而不是最后补

## 3. 总体实施原则

- 先做 `收盘后静态结果`，再做 `次日盘中动态信号`
- 先让系统能稳定产出 `主线 + 默认组合 + 解释`，再引入 `低置信度 + 价格偏离 + 盘中信号`
- 先冻结后端规则与 API 骨架，再推进前端整合
- 测试不放到最后一次性补，而是跟随每个阶段同步进入
- 每个阶段都要允许“降级但可用”，避免追求一步到位导致整体不可交付

## 4. 推荐实施顺序

推荐整体顺序如下：

1. 后端静态决策引擎
2. API / Schema 骨架
3. 前端二次决策静态页面
4. 后端盘中信号与低置信度
5. API 盘中增量接口
6. 前端盘中状态与行动清单
7. 测试联调、回归与验收

这是最小风险顺序。原因是：

- 如果没有稳定的后端静态结果，前端无法准确搭页面
- 如果 API / Schema 不先定，前后端会反复改字段
- 如果盘中逻辑先做，复杂度会过早膨胀

## 5. 里程碑拆分

### M0：基线准备

目标：

- 明确本功能是在现有强势筛选页内新增 `二次决策` Tab
- 确认复用现有候选池与 `standard / aggressive` 结果
- 冻结首版字段命名、枚举命名与状态机草案

交付物：

- 字段清单初版
- 状态枚举初版
- 页面区块草图

### M1：收盘后二次决策静态版

目标：

- 支持主线识别
- 支持默认组合排序
- 支持推荐 / 落选解释
- 支持证据区静态结果

交付物：

- 后端静态决策结果
- 静态 API
- 前端二次决策页静态版
- 第一轮规则单测

### M2：盘中信号增强版

目标：

- 支持开盘前 / 开盘后 30 分钟 / 开盘后 60 分钟状态更新
- 支持低置信度
- 支持价格偏离过大
- 支持建议买 / 不建议买收口

交付物：

- 盘中信号判定
- 盘中接口
- 前端盘中信号 UI
- 联调测试

### M3：策略健康与停用 / 恢复版

目标：

- 支持 20 / 60 日窗口状态
- 支持停用、观察、恢复状态
- 完成完整状态闭环

交付物：

- 策略健康判定模块
- 停用 / 恢复页面表达
- 验收用例

## 6. 后端实施顺序

### 6.1 第一阶段：静态决策核心

优先级：`P0`

任务：

1. 新增 `MomentumSecondaryDecisionService`
2. 实现主线识别模块
3. 实现角色识别模块
4. 实现默认组合排序模块
5. 实现推荐理由与落选主因输出
6. 实现证据区静态组装

依赖：

- 现有候选池结果
- 板块 / 行业映射
- 历史验证统计结果

交付字段建议：

- `action_level`
- `themes`
- `portfolio`
- `excluded_candidates`
- `evidence.theme_validation`
- `evidence.today_reasoning`

### 6.2 第二阶段：买点与偏离规则

优先级：`P0`

任务：

1. 实现 `买点清晰` 判定
2. 实现 `最优买入区 / 次优区 / 追高上限 / 失效位` 计算
3. 实现 `价格偏离过大` 判定
4. 为主仓 / 次仓 / 观察仓补充执行状态字段

关键规则：

- 龙头核心最优买入区宽度 `<= 2%`
- 前排换手最优买入区宽度 `<= 3%`
- 前排换手相对均价线偏离度 `> 3%` 时可触发 `不建议追入`

### 6.3 第三阶段：盘中信号与低置信度

优先级：`P1`

任务：

1. 实现开盘前预期强弱计算
2. 实现开盘后 30 分钟掉队识别
3. 实现开盘后 60 分钟结论收口
4. 实现 `低置信度` 触发与恢复
5. 实现盘中状态枚举与原因输出

关键输出：

- `confidence_level`
- `can_emit_buy_signal`
- `recovery_conditions`
- `watch_items`

### 6.4 第四阶段：策略健康状态

优先级：`P1`

任务：

1. 接入 20 / 60 日窗口验证结果
2. 实现 `healthy / partial_healthy / recovery_mode / disabled`
3. 实现停用 / 恢复判定逻辑
4. 实现停用态下的页面输出裁剪

## 7. API / Schema 实施顺序
