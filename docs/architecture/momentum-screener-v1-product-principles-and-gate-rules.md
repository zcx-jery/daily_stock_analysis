## 2. V1 总目标

V1 不是调参工具，也不是研究平台。

V1 的目标是做一套 **标准化生产系统**：

1. 每天从全市场统一筛出强势候选池。
2. 基于同一套候选池完成 `Standard` 官方主链路与 `Aggressive` 补充观察层。
3. 为后续回测、胜率验证、策略校准和自动进化提供稳定样本基线。

一句话总结：

**V1 先做稳定生产系统，不做高自由度实验系统。**

## 3. V1 入口标准

### 3.1 市场范围

V1 的“全市场”先定义为 A 股中的：

- 主板
- 创业板
- 科创板

原则：

- 统一进池，不在入口层先排除创业板、科创板。
- 后续评分、买点、验证和胜率统计必须保留市场属性标签。

### 3.2 统一候选池硬门槛

V1 候选池固定使用同一套入口基准：

- 最小涨幅：`4%`
- 最小成交额：`2亿`
- 最小换手率：`2%`

这三个值是 **V1 统一候选池入口基准**，不因 `Standard / Aggressive` 改变。

### 3.3 用户可操作项

V1 普通用户主页面只保留：

- `交易日`

V1 普通用户主页面不再暴露：

- `最小涨幅`
- `最小成交额`
- `最小换手率`
- `评分画像` 并列切换
- `返回数量`

同时：

- V1 不保留研究模式。
- V1 不提供入口调参能力。

### 3.4 参数职责边界

- `4 / 2 / 2`：决定谁能进入候选池。
- `完整排序集`：决定 `Standard` 二次决策如何收口官方组合。
- `Top30`：固定官方页面展示、导出与回测对齐基线。
- `Aggressive`：只决定是否补出额外的进攻观察票，不改变官方主链路。

## 4. Standard / Aggressive 职责边界

### 4.1 共享层

两套画像共享：

- 全市场范围：主板 + 创业板 + 科创板
- 统一候选池入口：`4 / 2 / 2`
- 同一批候选池样本
- 同一份完整排序集
- 同一套市场环境判断框架
- 同一套主线识别框架
- 同一套总闸门边界
- 同一套官方 `Top30` 展示基线

一句话：

**入口统一，画像后置。**

### 4.2 Standard 的职责

`Standard` 是 V1 的 **官方生产引擎**，负责：

- 官方 `今日出手级别`
- 官方默认组合
- 官方 `主仓 / 次仓 / 观察仓`
- 官方 `Top30` 展示基线
- 官方执行顺序
- 官方“今天该不该做”的最终判断
- 官方回测

它更关注：

- 延续性
- 结构完整度
- 主线地位
- 风险约束
- 确定性

一句话：

**Standard 告诉你今天该不该做，优先做谁。**

### 4.3 Aggressive 的职责

`Aggressive` 是 V1 的 **进攻补充引擎**，负责：

- 在统一候选池里识别 `Standard 官方 Top3` 之外更有弹性的机会
- 只补充值得继续盯的新增进攻观察票
- 作为折叠式进攻观察层和独立诊断层存在

它更关注：

- 可参与性
- 承接
- 弹性
- 次日触发效率
- 短线爆发力

一句话：

**Aggressive 告诉你如果要进攻，哪里更有弹性。**

### 4.4 Aggressive 的硬边界

V1 必须遵守：

- `Standard` 是官方主结论。
- `Aggressive` 不能推翻总闸门。
- `Aggressive` 不能单独替代 `Standard` 成为官方组合。
- `Aggressive` 默认折叠，不与 `Standard` 并列呈现主结论。
- 若 `Standard` 判定 `仅观察` 或 `今日不做`，`Aggressive` 只能补充进攻观察价值，不能翻盘成正式执行结论。

### 4.5 Aggressive 的波动容忍

V1 对 `Aggressive` 增加一条明确边界：

- 允许更高波动容忍。
- 单票振幅容忍上限放宽到 `10%`。
- 但风险红线不能被突破：至少排除 `明显追高 / 没有买点区间 / 已接近失效位` 三类硬伤。

说明：

- 这条规则属于 `Aggressive` 的后置评估规则。
- 不属于候选池统一入口规则。
- 候选池入口仍然固定为 `4 / 2 / 2`。

### 4.6 Aggressive 的展示规则

- 只有当 `Aggressive` 补出 `不在 Standard 官方 Top3` 内的新票，且该票同时满足 `高进攻度 + 买点相对清晰 + 不推翻 Standard 总闸门` 时，页面才提示“可展开查看”。
- `高进攻度` 定义为：`弹性高 + 主线里有地位 + 风险不过红线`。
- `买点相对清晰` 比 `Standard` 宽半档：允许 `等待触发` 进入补充观察，但必须已经具备 `买点区间 + 触发条件 + 非明显追高`。
- `Aggressive` 不展示与 `Standard 官方 Top3` 重复的票，只展示新增补充票。
- `Aggressive` 最多展示 `2` 只新增补充票，按 `进攻弹性` 排序。
- 每张 `Aggressive` 卡片都展示完整观察信息：`进攻理由 / 主线角色 / 买点区间 / 触发条件 / 失效位`，并持续标注 `仅补充观察，不纳入官方组合`。
- `Aggressive` 可进入独立的 `进攻观察清单`，但必须与 `Standard 官方行动清单` 分开展示。
- 即使 `Aggressive` 补充票次日先触发，也不能升格替代 `Standard` 的官方顺序。

### 4.7 Aggressive 的治理与回测

- 官方回测只回放 `Standard 官方链路`，不再区分 `Standard / Aggressive` 两套官方回测画像。
- `Aggressive` 只保留 `补充增益率` 诊断，不进入官方胜率口径。
- `补充增益率` 定义为：`Aggressive` 补充票不在 `Standard 官方 Top3` 中，且其后续表现优于 `Standard 观察仓` 或未入选边界票的比例。
- 当 `20日补充增益率 < 20%` 且 `60日补充增益率 < 25%` 时，`Aggressive` 进入 `待校准`。
- 当 `20日补充增益率 >= 25%` 时，进入 `观察恢复`；当 `60日补充增益率 >= 30%` 时，进入 `完全恢复`。
- 内部保留四态：`正常 / 待校准 / 观察恢复 / 完全恢复`；用户侧只显示简化三态：`正常 / 增益有限 / 恢复中`。
- 当用户侧显示 `增益有限` 时，统一解释为：`当前进攻补充层近期有效增益偏少，仅保留观察参考。`

## 5. 新总闸门总原则

新的总原则只有一句话：

**先判断今天能不能进攻，再判断这套主线值不值得信。**

V1 从这一版开始，用户侧不再使用“策略健康”这个总词。

新的总闸门拆成两张独立卡：

- `20日进攻许可`
- `60日主线可信度`

它们与 `今日出手级别` 的关系如下：

- `市场环境 × 机会质量` 先决定基础动作级别。
- `20日进攻许可` 决定当天动作上限。
- `60日主线可信度` 只做结构信任提示，不再直接硬压当天动作。

## 6. 20日进攻许可

### 6.1 核心职责

`20日进攻许可` 回答的问题是：

**最近这套系统，还能不能正常进攻。**

它不再考“默认组合最近是不是几乎天天优秀”，而是优先考：

- 买点是否先触发；
- 触发后的单票是否真的打出可执行利润窗口。

### 6.2 成功样本定义

单个历史样本日是否命中，按“买点先触发，再看利润窗口”判断。

角色门槛如下：

- 龙头核心：`>= 2.0%`
- 前排换手：`>= 2.5%`
- 观察备选：`>= 1.5%`

### 6.3 状态分档

`20日进攻许可` 的主状态只看“买点触发后的单票命中率”。

- `可进攻`：命中率 `>= 55%`
- `恢复中`：命中率 `>= 40%`
- `暂停进攻`：其余情况

最小有效样本门槛如下：

- 判 `可进攻`：至少 `5` 个有效样本
- 判 `恢复中`：至少 `3` 个有效样本

### 6.4 组合整体表现的角色

默认组合整体表现只做：

- 分数微调
- 解释增强

但不再直接改变 `可进攻 / 恢复中 / 暂停进攻` 的主状态。

### 6.5 用户侧状态词

页面用户侧固定使用：

- `可进攻`
- `恢复中`
- `暂停进攻`

## 7. 60日主线可信度

### 7.1 核心职责

`60日主线可信度` 回答的问题是：

**这套主线识别框架最近值不值得信。**

它不再承担“今天能不能做”的硬刹车职责，而是成为结构信任提示层。

### 7.2 判定对象

`60日主线可信度` 只把“第一主线”作为主判定对象。

- 第二主线可以用于补充解释；
- 但不主导 `60日` 的主结论。

### 7.3 单日评分

单个交易日按分层记分：

- 次日最强核心票命中第一主线：`0.6`
- 第一主线覆盖次日强票 `Top3` 至少 `2` 只：`0.4`
- 第一主线覆盖次日强票 `Top5` 至少 `3` 只：额外 `+0.1`

单日总分封顶为 `1.0`。

### 7.4 状态分档

最近 `60` 日取平均单日得分，映射成三档：

- `可信`：平均得分 `>= 0.60`
- `恢复中`：平均得分 `>= 0.45`
- `存疑`：其余情况

最小有效样本门槛如下：

- 判 `可信`：至少 `12` 个有效样本
- 判 `恢复中`：至少 `8` 个有效样本

### 7.5 用户侧状态词

页面用户侧固定使用：

- `可信`
- `恢复中`
- `存疑`

## 8. 市场环境

### 8.1 核心问题

`市场环境` 回答的问题不是“大盘红不红”，而是：

**市场今天愿不愿意继续为强势股付溢价。**

### 8.2 样本池

`市场环境` 采用双层样本池：

- `昨日二次决策 Top3`：看核心溢价
- `昨日候选池 Top10`：看广度溢价

### 8.3 核心溢价

若昨日二次决策 `Top3` 中，今天至少有 `1` 只：

- 先满足买点触发；
- 再打出 `T+1/T+2 利润窗口 >= 2.0%`；

则记为“核心有溢价”。

### 8.4 广度溢价

若昨日候选池 `Top10` 同时满足：

- 命中率 `>= 30%`
- 平均利润窗口 `>= 2.0%`

则记为“广度达标”。

### 8.5 三档结论

- `强`：核心有溢价，且广度达标
- `中等`：只好一边
- `弱`：核心无溢价，且广度不达标

## 9. 机会质量

### 9.1 核心问题

`机会质量` 回答的问题是：

**今天系统手上的这批票，是否足够适合出手。**

它只看当天手里的具体机会，不替代市场环境。

### 9.2 三层判断顺序

按以下顺序判断：

1. 买点清晰度
2. 默认组合盈亏比
3. 主线集中度

### 9.3 买点清晰度

按默认组合中“买点清晰 / 可执行”的票数分档：

- `3只清晰 = 强`
- `2只清晰 = 中上`
- `1只清晰 = 中`
- `0只清晰 = 弱`

### 9.4 默认组合盈亏比

默认组合盈亏比口径为：

**预期利润空间 vs 预期失效空间**

聚合方式采用：

- `主仓优先`
- `次仓 / 观察仓轻修正`

主仓最低门槛为：

- `预期利润空间 >= 预期失效空间的 1.5 倍`

### 9.5 主线集中度

第一版采用简单稳定的判断：

- 默认组合里至少 `2` 只来自第一主线

### 9.6 合成边界

先由买点清晰度决定主档，再由盈亏比和主线集中度修正。

- `3只清晰`
  - 默认 `强`
  - 只有主仓盈亏比不过线时，才允许下调
- `2只清晰`
  - 默认 `中上`
  - 只有“主仓盈亏比过线 + 主线集中度达标”时，才允许上调到 `强`
- `1只清晰`
  - 默认 `中`
  - 主仓盈亏比过线，则维持 `中`
  - 不过线，则降为 `弱`
- `0只清晰`
  - 固定 `弱`
  - 不允许被其他条件抬高

## 10. 今日出手级别主矩阵

主矩阵先由 `市场环境 × 机会质量` 决定基础动作级别：

| 市场环境 \\ 机会质量 | 强 | 中上 | 中 | 弱 |
| --- | --- | --- | --- | --- |
| 强 | 强烈可做 | 可正常出手 | 谨慎出手 | 仅观察 |
| 中等 | 可正常出手 | 谨慎出手 | 仅观察 | 今日不做 |
| 弱 | 谨慎出手 | 仅观察 | 今日不做 | 今日不做 |

## 11. 20日进攻许可封顶规则

主矩阵给出基础结论后，再由 `20日进攻许可` 封顶：

- `可进攻`
  - 不压级
- `恢复中`
  - 最高封顶到 `可正常出手`
- `暂停进攻`
  - 若 `市场环境强 + 机会质量强`，最高保留到 `谨慎出手`
  - 若只强一边，最高 `仅观察`
  - 若两边都不强，直接 `今日不做`

## 12. 停用与恢复

### 12.1 今日不做

`今日不做` 是单日结论，不等于系统长期停用。

### 12.2 系统停用

`系统停用` 只有在以下条件下触发：

- 连续 `5` 个交易日
- `20日进攻许可 = 暂停进攻`
- 且 `60日主线可信度 = 存疑`

### 12.3 退出停用

若系统已进入停用，满足以下条件可先退出停用：

- `20日进攻许可` 从 `暂停进攻` 回到 `恢复中`
- 且当天 `市场环境` 不再是 `弱`

退出停用后只恢复到：

- `仅观察`
- 或最多 `谨慎出手`

### 12.4 恢复正常

当 `20日进攻许可 = 可进攻` 时，允许恢复到：

- `可正常出手`

### 12.5 重新允许强烈可做

只有同时满足以下条件时，才允许重新出现 `强烈可做`：

- `20日进攻许可 = 可进攻`
- `市场环境 = 强`
- `机会质量 = 强`

## 13. 页面表达

### 13.1 用户侧旧词替换

页面用户侧彻底移除：

- `策略健康`

统一替换为两张独立卡：

- `20日进攻许可`
- `60日主线可信度`

### 13.2 卡片结构

两张卡统一展示：

- 一句结论
- 分数和状态
- 一句解释

### 13.3 顶部摘要

页面顶部在 `今日出手级别` 区域并排摘要两张卡的结论：

- `20日进攻许可：...`
- `60日主线可信度：...`

### 13.4 冲突场景表达

若当天 `今日出手级别` 仍可做，但 `60日主线可信度 = 存疑`：

- 不自动下调动作级别
- 顶部新增黄色风险提示条

提示语义为：

**今天可做，但这套主线结构的可信度在下降，信任度要打折。**

## 14. V1 最短版

如果只记 V1 当前版本最核心的产品原则，可以直接记这 `10` 条：

1. V1 是标准化生产系统，不是调参工具。
2. 候选池入口固定为全市场统一 `4 / 2 / 2`。
3. 普通用户不再修改入口参数，也不再修改 `TopN`；官方展示固定 `Top30`。
4. `Standard` 是唯一官方生产引擎，`Aggressive` 是折叠式进攻补充观察层。
5. 新总原则是：先判断今天能不能进攻，再判断这套主线值不值得信。
6. 用户侧不再使用“策略健康”，而是拆成 `20日进攻许可` 与 `60日主线可信度`。
7. `20日进攻许可` 决定动作上限，`60日主线可信度` 只做结构提示。
8. `今日出手级别` 先看 `市场环境 × 机会质量`，再由 `20日进攻许可` 封顶。
9. `今日不做` 与 `系统停用` 必须分开；停用只在连续 `5` 个交易日 `20日暂停进攻 + 60日存疑` 时触发。
10. 官方回测只看 `Standard`，`Aggressive` 只保留补充增益率诊断与治理状态。
