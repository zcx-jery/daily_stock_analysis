## 2. V1 总目标

V1 不是调参工具，也不是研究平台。  
V1 的目标是做一套 **标准化生产系统**：

1. 每天从全市场统一筛出强势候选池。
2. 再基于同一套候选池做 `Standard / Aggressive` 评分、二次决策和执行辅助。
3. 为后续回测、胜率验证、策略健康与自动进化提供稳定样本基准。

一句话总结：

**V1 先做稳定生产系统，不做高自由度实验系统。**

## 3. V1 入口标准

### 3.1 市场范围

V1 的“全市场”先定义为 A 股中的：

- 主板
- 创业板
- 科创板

原则：

- 统一进池，不在入口层先排除创业板、科创板。
- 后续评分、买点、验证和胜率统计必须保留市场属性标签。

### 3.2 统一候选池硬门槛

V1 候选池固定使用同一套入口基准：

- 最小涨幅：`5%`
- 最小成交额：`3亿`
- 最小换手率：`3%`

这三个值是 **V1 统一候选池入口基准**，不因 `Standard / Aggressive` 改变。

### 3.3 用户可操作项

V1 普通用户主页面只保留：

- `交易日`
- `评分画像`
- `返回数量`

V1 普通用户主页面不再暴露：

- `最小涨幅`
- `最小成交额`
- `最小换手率`

同时：

- V1 不保留研究模式。
- V1 不提供调参入口。

### 3.4 参数职责边界

- `5 / 3 / 3`：决定谁能进入候选池。
- `Standard / Aggressive`：决定候选池内如何评分、排序、收口。
- `返回数量`：只影响页面展示和导出，不影响二次决策本身。

## 4. Standard / Aggressive 职责边界

### 4.1 共享层

两套画像共享：

- 全市场范围：主板 + 创业板 + 科创板
- 统一候选池入口：`5 / 3 / 3`
- 同一批候选池样本
- 同一市场环境判断
- 同一主线识别框架
- 同一总闸门边界

也就是：

**入口统一，画像后置。**

### 4.2 Standard 的职责

`Standard` 是 V1 的 **官方生产引擎**，负责：

- 官方 `今日出手级别`
- 官方默认组合
- 官方 `主仓 / 次仓 / 观察仓`
- 官方执行顺序
- 官方“今天该不该做”的判断

它更关注：

- 延续性
- 结构完整度
- 主线地位
- 风险约束
- 确定性

一句话：

**Standard 告诉你今天该不该做，优先做谁。**

### 4.3 Aggressive 的职责

`Aggressive` 是 V1 的 **进攻补充引擎**，负责：

- 在统一候选池里识别更有弹性的机会
- 提示哪些票更容易形成强买点
- 作为进攻型观察和补充视图存在

它更关注：

- 可参与性
- 承接
- 弹性
- 次日触发效率
- 短线爆发力

一句话：

**Aggressive 告诉你如果要进攻，哪里更有弹性。**

### 4.4 Aggressive 的硬边界

V1 必须遵守：

- `Standard` 是官方主结论。
- `Aggressive` 不能推翻总闸门。
- `Aggressive` 不能单独替代 `Standard` 成为官方组合。
- 如果 `Standard` 判定 `仅观察` 或 `今日不做`，`Aggressive` 只能补充进攻观察价值，不能翻盘成正式执行结论。

### 4.5 Aggressive 的波动容忍

V1 对 `Aggressive` 增加一条明确边界：

- 允许更高波动容忍。
- 单票振幅容忍上限放宽到 `10%`。

说明：

- 这条规则属于 `Aggressive` 的后置评估规则。
- 不属于候选池统一入口规则。
- 候选池入口仍然固定为 `5 / 3 / 3`。

## 5. V1 总闸门总体结构

V1 总闸门采用三层联合裁决：

1. `市场环境`
2. `当日机会质量`
3. `历史有效性`

合成原则：

1. `市场环境 × 当日机会质量` 先决定 `基础出手级别`
2. `历史有效性` 只负责给基础级别加上限
3. 最后再过硬门槛，防止出现“看起来能做、实际没法做”的误判

一句话：

- 市场层 = 看风
- 机会层 = 看货
- 历史层 = 控上限

## 6. 市场环境层

### 6.1 目标

市场环境层要回答的不是“大盘涨没涨”，而是：

**今天这个市场，适不适合短线强势股去延续。**

### 6.2 四个模块

#### 指数趋势

V1 看：

- 上证指数
- 创业板指
- 国证2000

定义：

- `强`
  - 3 个指数里至少 2 个站上 5 日线
  - 且近 3 日斜率向上
- `中`
  - 多空混合，没有明显共振向上，也没明显破位
- `弱`
  - 3 个指数里至少 2 个跌破 5 日线
  - 且近 3 日斜率向下

#### 赚钱效应

“昨日强势股样本”定义为：

- 昨日候选池 Top10
- 昨日二次决策输出的 3 只强票

两者取 **并集去重**，并拆成两层：

- `broad_sample`：昨日候选池 Top10
- `core_sample`：昨日二次决策 3 只强票

市场赚钱效应判断：

- 以 `core_sample` 为主
- 以 `broad_sample` 为辅

建议权重：

- `core_effect = 60%`
- `broad_effect = 40%`

V1 先看：

- 次日红盘率
- T+1 利润窗口
- T+2 利润窗口
- 明显闷杀比例
- 开盘后 60 分钟内是否给过合理参与机会

#### 情绪强弱

V1 看：

- 涨停家数 / 跌停家数
- 高标晋级率
- 炸板率

#### 主线扩散

V1 看：

- 是否存在清晰主线
- 主线是否有龙头 + 前排 + 跟随
- 主线内是否出现持续回流

### 6.3 建议权重

- 指数趋势：`25%`
- 赚钱效应：`35%`
- 情绪强弱：`25%`
- 主线扩散：`15%`

原则：

- `赚钱效应` 权重最高
- 即使上证偏强，只要赚钱效应和情绪同时偏弱，也不能判成强环境

### 6.4 输出

市场环境层只输出三档：

- `强`
- `中`
- `弱`

## 7. 当日机会质量层

### 7.1 目标

当日机会质量要回答的是：

**今天系统最后收口出来的这套 1-3 票，是否真的像一套可执行答案。**

### 7.2 五个指标

#### 主线清晰度

看：

- 前两条主线分差
- 主线内是否有龙头 + 前排 + 跟随
- 主线是否有持续回流，不是一日游

#### 默认组合质量

看：

- 是否真的收口出 1-3 只
- 主仓是否站得住
- 次仓是否和主仓形成互补
- 观察仓是否有确认价值，而不是凑数

#### 买点清晰度

围绕最终 3 只看：

- 主仓是否有清晰买点
- 次仓是否有清晰买点
- 观察仓是否至少有明确观察条件

硬规则：

- 如果主仓买点不清晰，当日机会质量不能判强。

#### 角色结构完整度

看：

- 主仓是否是最强执行对象
- 次仓是否承担进攻或换手补充
- 观察仓是否承担主线确认

#### 风险可控度

看：

- 是否普遍偏离买点区间过大
- 是否大量高位加速、追高风险明显
- 是否组合里大多是“强，但不建议追”

硬规则：

- 如果主仓和次仓都处于“明显偏离过大 / 不建议追入”，当日机会质量不能判强。

### 7.3 建议权重

- 主线清晰度：`30%`
- 默认组合质量：`25%`
- 买点清晰度：`25%`
- 角色结构完整度：`10%`
- 风险可控度：`10%`

### 7.4 输出

当日机会质量层只输出三档：

- `强`
- `中`
- `弱`

## 8. 历史有效性层

### 8.1 目标

历史有效性层回答的是：

**这套方法最近是不是还靠谱。**

V1 继续保留：

- `20日当前可用性`
- `60日结构可信度`

### 8.2 角色边界

V1 明确规定：

- 历史有效性层不再单独决定“今天做不做”
- 它只负责控制推荐上限

### 8.3 输出

V1 先收成三档：

- `健康`
- `一般`
- `偏弱`

对应上限：

- `健康`
  - 最高可到 `强烈可做`
- `一般`
  - 最高可到 `可正常出手`
- `偏弱`
  - 最高可到 `谨慎出手`

这意味着：

- 即使 `20日/60日` 偏弱
- 也不再直接等于 `今日不做`
- 而是最多只能给到 `谨慎出手`

## 9. 今日出手级别合成规则

### 9.1 基础矩阵

先由 `市场环境 × 当日机会质量` 决定基础出手级别：

| 市场环境 \\ 当日机会质量 | 强 | 中 | 弱 |
| --- | --- | --- | --- |
| 强 | `可正常出手` | `谨慎出手` | `仅观察` |
| 中 | `谨慎出手` | `仅观察` | `仅观察` |
| 弱 | `仅观察` | `今日不做` | `今日不做` |

### 9.2 历史有效性控上限

- `历史健康`
  - 不额外压制
- `历史一般`
  - 最高 `可正常出手`
- `历史偏弱`
  - 最高 `谨慎出手`

### 9.3 强烈可做升级条件

`强烈可做` 不直接从基础矩阵给出，而是额外升级满足：

- 市场环境 = `强`
- 当日机会质量 = `强`
- 历史有效性 = `健康`
- 核心赚钱效应 = `强`
- 主仓、次仓都具备清晰买点
- 没有明显“偏离过大 / 不建议追入”

### 9.4 最终五档

- `强烈可做`
- `可正常出手`
- `谨慎出手`
- `仅观察`
- `今日不做`

## 10. 五档级别对应的执行权限

### 10.1 强烈可做

- 推荐上限：`full`
- 最多输出：`3 只`
- 行动清单：完整版
- 次日盘中允许发“建议买”信号：`是`

### 10.2 可正常出手

- 推荐上限：`full`
- 最多输出：`2-3 只`
- 行动清单：完整版
- 次日盘中允许发“建议买”信号：`是`

### 10.3 谨慎出手

- 推荐上限：`limited`
- 最多输出：`1-2 只`
- 行动清单：简化版
- 次日盘中允许发“建议买”信号：`有限允许`

硬规则：

- `谨慎出手` 下，盘中最多只允许 1 只票进入“建议买”判断。

### 10.4 仅观察

- 推荐上限：`observe`
- 最多输出：`1-3 只观察对象`
- 行动清单：不生成
- 次日盘中允许发“建议买”信号：`否`

### 10.5 今日不做

- 推荐上限：`blocked`
- 最多输出：`0 只强推荐`
- 行动清单：不生成
- 次日盘中允许发“建议买”信号：`否`

页面必须明确表达：

- `今天不建议买`
- `即使个别票看起来还行，也不建议执行`

## 11. 行动清单规则

### 11.1 哪些级别有行动清单

- `强烈可做`
  - 完整版行动清单
- `可正常出手`
  - 完整版行动清单
- `谨慎出手`
  - 简化版行动清单
- `仅观察 / 今日不做`
  - 不生成行动清单

### 11.2 完整版行动清单

适用于：

- `强烈可做`
- `可正常出手`

目标：

1. 明天最先盯谁
2. 谁掉队就先排除
3. 哪些条件触发才允许考虑买
4. 到 60 分钟时，最后结论怎么收口

结构固定为三个时段：

- `开盘前`
- `开盘后 30 分钟`
- `开盘后 60 分钟`

### 11.3 简化版行动清单

适用于：

- `谨慎出手`

目标：

- 只帮用户明确哪一只值得重点等
- 明确什么情况下直接放弃
- 防止多票并行执行带来误操作

结构仍保留三个时段，但内容明显收缩：

- `开盘前`
  - 只回答唯一重点盯谁
- `开盘后 30 分钟`
  - 只回答主仓有没有明显走坏
- `开盘后 60 分钟`
  - 必须收口成 `仅主仓可考虑` 或 `今天不建议买`

## 12. 盘中信号页硬纪律

盘中信号页是：

**对前一晚已确定顺序和权限的盘中状态播报器。**

它不负责：

- 重排主仓 / 次仓 / 观察仓
- 推翻总闸门
- 临时新增股票
- 在不允许的场景里给出追入暗示

### 12.1 四条硬纪律

1. **不改昨晚顺序**
   - 盘中不能重排主仓 / 次仓 / 观察仓
2. **不推翻总闸门**
   - 前一晚 `仅观察 / 今日不做`，第二天盘中不能翻成 `建议买`
3. **不对偏离过大的票给追入暗示**
   - 只能明确提示 `不建议追入`
4. **不凭盘中情绪临时新增股票**
   - 盘中只跟踪前一晚已进入组合的票

### 12.2 单票允许输出的结论

每只票只允许输出：

- `买点已触发`
- `接近触发`
- `尚未触发`
- `触发失败`
- `偏离过大`
- `保留观察`

### 12.3 整页允许输出的最终结论

整页最终只允许收口成：

- `建议买`
- `仅主仓可考虑`
- `保留观察但不建议执行`
- `不建议买`

### 12.4 不同出手级别下的边界

- `强烈可做 / 可正常出手`
  - 允许盘中正式收口成 `建议买`
- `谨慎出手`
  - 只允许主仓进入正式买入判断
- `仅观察`
  - 不允许出现 `建议买`
- `今日不做`
  - 明确禁止任何 `建议买`

### 12.5 盘中页禁止语言

在 `仅观察 / 今日不做 / 偏离过大` 场景下，盘中页禁止出现：

- `可以直接上`
- `建议积极参与`
- `可追`
- `可跟`
- `盘中转强可立即买入`

### 12.6 60 分钟收口要求

到开盘后 60 分钟内，盘中页必须收口成：

- `建议买`
- `仅主仓可考虑`
- `保留观察但不建议执行`
- `不建议买`

不能长期停留在模糊状态。

## 13. V1 最短版本

如果只记 V1 的最核心产品原则，可以直接记这 8 条：

1. V1 是标准化生产系统，不是调参工具。
2. 候选池入口固定为全市场统一 `5 / 3 / 3`。
3. 普通用户不可修改入口参数，V1 不保留研究模式。
4. 筛选范围固定为主板 + 创业板 + 科创板。
5. `Standard` 是官方生产引擎，负责最终主结论。
6. `Aggressive` 是进攻补充引擎，允许更高波动，振幅容忍上限 `10%`。
7. 总闸门改为 `市场环境 × 当日机会质量 × 历史有效性` 联合裁决。
8. 历史有效性只控上限，不再单独一票否决。
