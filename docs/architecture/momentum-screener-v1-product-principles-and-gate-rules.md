## 2. V1 总目标

V1 不是调参工具，也不是研究平台。

V1 的目标是做一套 **标准化生产系统**：

1. 每天从全市场统一筛出强势候选池。
2. 基于同一套候选池完成 `Standard` 官方主链路与 `Aggressive` 补充观察层。
3. 为后续回测、胜率验证、策略校准和自动进化提供稳定样本基线。

一句话总结：

**V1 先做稳定生产系统，不做高自由度实验系统。**

### 2.1 V1.3 主线增强定位

V1.3 是建立在 `6000` 积分数据权限上的主线增强版本。

V1.3 不购买股票实时分钟、股票历史分钟等独立分钟权限，因此不把目标定义为“正式分钟级盘中买点系统”。

V1.3 的目标是把强势筛选从 **单股排序** 升级为 **主线驱动的短线决策系统**：

- 用 `ths_member` 建立股票到题材 / 概念 / 主线的映射。
- 用 `limit_list_d`、`stk_limit` 和 `ths_hot` 补强短线情绪、涨停炸板、连板高度和热门主线证据。
- 用主线强度、短线情绪和角色地位辅助 `Standard` 官方 Top3 收口。
- 用回测诊断拆分失败原因，明确错在主线、情绪、角色、价格位置还是总闸门。

一句话：

**V1.3 不追求更激进地喊买点，而是让系统更准确地判断今天哪条主线、哪几只核心票值得认真看。**

### 2.2 V1.4 回测结算口径

V1.4 起，回测胜率主口径从“`T+2` 收盘是否正收益”调整为“短线延续合格率”：

- `T+1` 方向确认：`T+1 收盘价 > T+1 开盘价`
- `T+2` 兑现窗口：`T+2 最高价 > T+1 收盘价`
- 两者同时满足，才认为 `T` 日选股方向合格。

这个口径更贴近短线目标：先判断次日是否有资金延续，再判断后日是否给过卖出窗口。`T+2 利润窗口`、`T+2 最大回撤` 和 `买点触发率` 继续保留为执行质量指标。

## 3. V1 入口标准

### 3.1 市场范围

V1 的“全市场”先定义为 A 股中的：

- 主板
- 创业板
- 科创板

原则：

- 统一进池，不在入口层先排除创业板、科创板。
- 后续评分、买点、验证和胜率统计必须保留市场属性标签。

### 3.2 统一候选池硬门槛

V1 候选池固定使用同一套入口基准：

- 最小涨幅：`4%`
- 最小成交额：`2亿`
- 最小换手率：`2%`

这三个值是 **V1 统一候选池入口基准**，不因 `Standard / Aggressive` 改变。

### 3.3 用户可操作项

V1 普通用户主页面只保留：

- `交易日`

V1 普通用户主页面不再暴露：

- `最小涨幅`
- `最小成交额`
- `最小换手率`
- `评分画像` 并列切换
- `返回数量`

同时：

- V1 不保留研究模式。
- V1 不提供入口调参能力。

### 3.4 参数职责边界

- `4 / 2 / 2`：决定谁能进入候选池。
- `完整排序集`：决定 `Standard` 二次决策如何收口官方组合。
- `Top30`：固定官方页面展示、导出与回测对齐基线。
- `Aggressive`：只决定是否补出额外的进攻观察票，不改变官方主链路。

## 4. Standard / Aggressive 职责边界

### 4.1 共享层

两套画像共享：

- 全市场范围：主板 + 创业板 + 科创板
- 统一候选池入口：`4 / 2 / 2`
- 同一批候选池样本
- 同一份完整排序集
- 同一套市场环境判断框架
- 同一套主线识别框架
- 同一套总闸门边界
- 同一套官方 `Top30` 展示基线

一句话：

**入口统一，画像后置。**

### 4.2 Standard 的职责

`Standard` 是 V1 的 **官方生产引擎**，负责：

- 官方 `今日出手级别`
- 官方默认组合
- 官方 `主仓 / 次仓 / 观察仓`
- 官方 `Top30` 展示基线
- 官方执行顺序
- 官方“今天该不该做”的最终判断
- 官方回测

它更关注：

- 延续性
- 结构完整度
- 主线地位
- 风险约束
- 确定性

一句话：

**Standard 告诉你今天该不该做，优先做谁。**

### 4.3 Aggressive 的职责

`Aggressive` 是 V1 的 **进攻补充引擎**，负责：

- 在统一候选池里识别 `Standard 官方 Top3` 之外更有弹性的机会
- 只补充值得继续盯的新增进攻观察票
- 作为折叠式进攻观察层和独立诊断层存在

它更关注：

- 可参与性
- 承接
- 弹性
- 次日触发效率
- 短线爆发力

一句话：

**Aggressive 告诉你如果要进攻，哪里更有弹性。**

### 4.4 Aggressive 的硬边界

V1 必须遵守：

- `Standard` 是官方主结论。
- `Aggressive` 不能推翻总闸门。
- `Aggressive` 不能单独替代 `Standard` 成为官方组合。
- `Aggressive` 默认折叠，不与 `Standard` 并列呈现主结论。
- 若 `Standard` 判定 `仅观察` 或 `今日不做`，`Aggressive` 只能补充进攻观察价值，不能翻盘成正式执行结论。

### 4.5 Aggressive 的波动容忍

V1 对 `Aggressive` 增加一条明确边界：

- 允许更高波动容忍。
- 单票振幅容忍上限放宽到 `10%`。
- 但风险红线不能被突破：至少排除 `明显追高 / 没有买点区间 / 已接近失效位` 三类硬伤。

说明：

- 这条规则属于 `Aggressive` 的后置评估规则。
- 不属于候选池统一入口规则。
- 候选池入口仍然固定为 `4 / 2 / 2`。

### 4.6 Aggressive 的展示规则

- 只有当 `Aggressive` 补出 `不在 Standard 官方 Top3` 内的新票，且该票同时满足 `高进攻度 + 买点相对清晰 + 不推翻 Standard 总闸门` 时，页面才提示“可展开查看”。
- `高进攻度` 定义为：`弹性高 + 主线里有地位 + 风险不过红线`。
- `买点相对清晰` 比 `Standard` 宽半档：允许 `等待触发` 进入补充观察，但必须已经具备 `买点区间 + 触发条件 + 非明显追高`。
- `Aggressive` 不展示与 `Standard 官方 Top3` 重复的票，只展示新增补充票。
- `Aggressive` 最多展示 `2` 只新增补充票，按 `进攻弹性` 排序。
- 每张 `Aggressive` 卡片都展示完整观察信息：`进攻理由 / 主线角色 / 买点区间 / 触发条件 / 失效位`，并持续标注 `仅补充观察，不纳入官方组合`。
- `Aggressive` 可进入独立的 `进攻观察清单`，但必须与 `Standard 官方行动清单` 分开展示。
- 即使 `Aggressive` 补充票次日先触发，也不能升格替代 `Standard` 的官方顺序。

### 4.7 Aggressive 的治理与回测

- 官方回测只回放 `Standard 官方链路`，不再区分 `Standard / Aggressive` 两套官方回测画像。
- `Aggressive` 只保留 `补充增益率` 诊断，不进入官方胜率口径。
- `补充增益率` 定义为：`Aggressive` 补充票不在 `Standard 官方 Top3` 中，且其后续表现优于 `Standard 观察仓` 或未入选边界票的比例。
- 当 `20日补充增益率 < 20%` 且 `60日补充增益率 < 25%` 时，`Aggressive` 进入 `待校准`。
- 当 `20日补充增益率 >= 25%` 时，进入 `观察恢复`；当 `60日补充增益率 >= 30%` 时，进入 `完全恢复`。
- 内部保留四态：`正常 / 待校准 / 观察恢复 / 完全恢复`；用户侧只显示简化三态：`正常 / 增益有限 / 恢复中`。
- 当用户侧显示 `增益有限` 时，统一解释为：`当前进攻补充层近期有效增益偏少，仅保留观察参考。`

## 5. 新总闸门总原则

新的总原则改为一句话：

**先由当天市场与机会决定能不能做，再用 20/60 判断该用多大力度相信。**

V1 从这一版开始，用户侧不再使用“策略健康”这个总词，也不再把 `20日` 和 `60日` 当成简单的“系统活着 / 系统死了”硬闸门。

新的总闸门拆成两张独立卡：

- `20日进攻温度`
- `60日结构信任度`

它们与 `今日出手级别` 的关系如下：

- `市场环境 × 机会质量` 先决定基础动作级别。
- `20日进攻温度` 判断最近短线环境是否适合主动进攻，用来调节进攻力度。
- `60日结构信任度` 判断主线、角色和组合框架是否仍值得相信，用来调节信任折扣。
- 只有在 `20日进攻温度 = 冰`、`60日结构信任度 = 失真`，且当天 `市场环境 / 机会质量` 不强时，才允许触发硬停用或明确劝退。

## 6. 20日进攻温度

### 6.1 核心职责

`20日进攻温度` 回答的问题是：

**最近 20 个交易日，短线强势股是否仍适合主动进攻。**

它不再只考“默认组合是否天天达成严格成功样本”，而是把强势股天然波动纳入口径，重点观察：

- 主仓最近是否仍能带来正向 T+2 表现；
- 官方 Top3 是否仍有足够利润窗口；
- 买点是否经常能触发，而不是长期只给观察；
- 平均回撤是否处在强势股可承受范围内；
- 系统是否因为过度谨慎错过明显机会。

### 6.2 评分因子

`20日进攻温度` 采用综合分，不再用单一命中率硬切。

| 因子 | 权重 | 解释 |
| --- | ---: | --- |
| 主仓 T+2 正收益率 | `30%` | 主仓是系统最重要的进攻锚，优先看它有没有持续赚钱能力。 |
| 官方 Top3 平均利润窗口 | `25%` | 判断默认组合是否仍能提供足够短线弹性。 |
| 买点触发率 | `15%` | 判断系统给出的买点是否真的可执行。 |
| 平均最大回撤 | `15%` | 强势股允许波动，但需要识别波动是否已明显失控。 |
| 错杀机会率 | `15%` | 判断系统是否因为过度谨慎，把实际有利润窗口的日期压成观察或不做。 |

### 6.3 状态分档

用户侧状态固定为四档：

| 状态 | 产品含义 | 动作影响 |
| --- | --- | --- |
| `热` | 最近进攻环境顺畅，主仓和 Top3 都有延续性。 | 不压级，允许出现 `强烈可做`。 |
| `温` | 仍可进攻，但需要控制节奏。 | 不硬压级，但文案提示适度收敛。 |
| `冷` | 近期胜率或触发质量下降，但并不等于系统失效。 | 默认降低进攻力度，优先保留主仓或少量推荐。 |
| `冰` | 最近强势股进攻反馈明显变差。 | 除非当天市场和机会都极强，否则最高只保留观察。 |

### 6.4 回撤口径

强势股不应套用过低波动阈值。

- `Standard` 主链路允许把 `5%` 左右平均回撤视为正常风险区。
- `Aggressive` 补充层允许个股存在最高约 `10%` 的波动预期，但不得推翻官方总闸门。
- 回撤只在明显失控时降温，不再因为短线强票的正常波动直接判定系统不可用。

## 7. 60日结构信任度

### 7.1 核心职责

`60日结构信任度` 回答的问题是：

**这套主线识别、角色分配和默认组合框架，最近 60 个交易日是否仍值得相信。**

它不再承担“今天能不能做”的硬刹车职责，而是成为长期结构可信度提示层。

### 7.2 评分因子

`60日结构信任度` 重点看结构是否真的有增益，而不是简单复用 20 日胜率。

| 因子 | 解释 |
| --- | --- |
| 官方 Top3 相对候选池 Top10 的超额收益 | 判断二次决策是否比候选池平均更会选。 |
| 官方 Top3 相对原始排序 Top3 的超额收益 | 判断二次决策是否真的提升了排序质量。 |
| 主仓相对次仓 / 观察仓的稳定优势 | 判断主仓定义是否有效，避免主仓长期弱于其他角色。 |
| 角色稳定性 | 判断龙头核心、前排换手、观察备选的分工是否仍然成立。 |
| 市场分层适配度 | 分别看强市、中性市、弱市下结构是否稳定，避免一套规则在所有环境里混用。 |
| 被限制后的错过机会率 | 判断长期结构是否被历史窗口过度压制。 |

### 7.3 状态分档

用户侧状态固定为四档：

| 状态 | 产品含义 | 动作影响 |
| --- | --- | --- |
| `可信` | 二次决策相对候选池和原始排序有稳定增益。 | 增强信任，不额外压级。 |
| `可参考` | 结构仍有参考价值，但优势不够稳定。 | 保持动作级别，提示信任折扣。 |
| `存疑` | 结构增益不稳定，容易选到对但排错。 | 不单独硬压级，但限制强信任表达。 |
| `失真` | 主线或角色框架已明显不能解释结果。 | 与 `20日冰` 叠加时才触发硬停用。 |

### 7.4 与当天动作的边界

`60日结构信任度` 不直接回答“今天买不买”，它只回答“今天这套结论该打几分信任”。

- 当天 `市场环境强 + 机会质量强` 时，即使 `60日结构信任度 = 存疑`，也不应自动压成 `今日不做`。
- 当 `60日结构信任度 = 失真` 时，页面必须提示“结构参考价值下降”，但是否劝退仍要看 `20日进攻温度` 与当天机会。
- 如果长期结构持续失真，后续优先进入规则校准与回测诊断，而不是让页面长期输出恒定停用。

## 8. 市场环境

### 8.1 核心问题

`市场环境` 回答的问题不是“大盘红不红”，而是：

**市场今天愿不愿意继续为强势股付溢价。**

### 8.2 样本池

`市场环境` 采用双层样本池：

- `昨日二次决策 Top3`：看核心溢价
- `昨日候选池 Top10`：看广度溢价

### 8.3 核心溢价

若昨日二次决策 `Top3` 中，今天至少有 `1` 只：

- 先满足买点触发；
- 再打出 `T+1/T+2 利润窗口 >= 2.0%`；

则记为“核心有溢价”。

### 8.4 广度溢价

若昨日候选池 `Top10` 同时满足：

- 命中率 `>= 30%`
- 平均利润窗口 `>= 2.0%`

则记为“广度达标”。

### 8.5 三档结论

- `强`：核心有溢价，且广度达标
- `中等`：只好一边
- `弱`：核心无溢价，且广度不达标

## 9. 机会质量

### 9.1 核心问题

`机会质量` 回答的问题是：

**今天系统手上的这批票，是否足够适合出手。**

它只看当天手里的具体机会，不替代市场环境。

### 9.2 三层判断顺序

按以下顺序判断：

1. 买点清晰度
2. 默认组合盈亏比
3. 主线集中度

### 9.3 买点清晰度

按默认组合中“买点清晰 / 可执行”的票数分档：

- `3只清晰 = 强`
- `2只清晰 = 中上`
- `1只清晰 = 中`
- `0只清晰 = 弱`

### 9.4 默认组合盈亏比

默认组合盈亏比口径为：

**预期利润空间 vs 预期失效空间**

聚合方式采用：

- `主仓优先`
- `次仓 / 观察仓轻修正`

主仓最低门槛为：

- `预期利润空间 >= 预期失效空间的 1.5 倍`

### 9.5 主线集中度

第一版采用简单稳定的判断：

- 默认组合里至少 `2` 只来自第一主线

### 9.6 合成边界

先由买点清晰度决定主档，再由盈亏比和主线集中度修正。

- `3只清晰`
  - 默认 `强`
  - 只有主仓盈亏比不过线时，才允许下调
- `2只清晰`
  - 默认 `中上`
  - 只有“主仓盈亏比过线 + 主线集中度达标”时，才允许上调到 `强`
- `1只清晰`
  - 默认 `中`
  - 主仓盈亏比过线，则维持 `中`
  - 不过线，则降为 `弱`
- `0只清晰`
  - 固定 `弱`
  - 不允许被其他条件抬高

## 10. 今日出手级别主矩阵

主矩阵先由 `市场环境 × 机会质量` 决定基础动作级别：

| 市场环境 \\ 机会质量 | 强 | 中上 | 中 | 弱 |
| --- | --- | --- | --- | --- |
| 强 | 强烈可做 | 可正常出手 | 谨慎出手 | 仅观察 |
| 中等 | 可正常出手 | 谨慎出手 | 仅观察 | 今日不做 |
| 弱 | 谨慎出手 | 仅观察 | 今日不做 | 今日不做 |

## 11. 20/60 联合校准规则

主矩阵给出基础结论后，再由 `20日进攻温度 × 60日结构信任度` 做力度校准。

| 20日进攻温度 \\ 60日结构信任度 | 可信 | 可参考 | 存疑 | 失真 |
| --- | --- | --- | --- | --- |
| 热 | 不压级，可强推 | 不压级，提示信任折扣 | 最高 `可正常出手` | 最高 `谨慎出手` |
| 温 | 不压级，文案收敛 | 最高 `可正常出手` | 最高 `谨慎出手` | 最高 `仅观察` |
| 冷 | 最高 `谨慎出手`，优先主仓 | 最高 `谨慎出手`，优先主仓 | 最高 `仅观察` | 最高 `仅观察` |
| 冰 | 最高 `仅观察` | 最高 `仅观察` | 最高 `今日不做` | `系统停用 / 今日不做` |

例外规则如下：

- 若 `市场环境 = 强` 且 `机会质量 = 强`，`20日进攻温度 = 冷` 时仍可保留到 `谨慎出手`。
- 若 `20日进攻温度 = 冰`，即使当天个别票看起来不错，也必须明确提示“仅允许观察，除非出现极端强市场与极清晰买点”。
- 若 `60日结构信任度 = 存疑`，但主仓买点清晰且主仓历史表现仍强，页面可以输出 `谨慎出手`，但不得使用“强烈可做”话术。

## 12. 停用与恢复

### 12.1 今日不做

`今日不做` 是单日结论，不等于系统长期停用。

### 12.2 系统停用

`系统停用` 只有在以下条件下触发：

- 连续 `5` 个交易日
- `20日进攻温度 = 冰`
- 且 `60日结构信任度 = 失真`
- 且当天 `市场环境 / 机会质量` 没有同时达到 `强`

### 12.3 退出停用

若系统已进入停用，满足以下条件可先退出停用：

- `20日进攻温度` 从 `冰` 回到 `冷` 或更高
- 且当天 `市场环境` 不再是 `弱`

退出停用后只恢复到：

- `仅观察`
- 或最多 `谨慎出手`

### 12.4 恢复正常

当 `20日进攻温度` 回到 `温` 或 `热` 时，允许恢复到：

- `可正常出手`

### 12.5 重新允许强烈可做

只有同时满足以下条件时，才允许重新出现 `强烈可做`：

- `20日进攻温度 = 热`
- `60日结构信任度` 不为 `失真`
- `市场环境 = 强`
- `机会质量 = 强`

## 13. 页面表达

### 13.1 用户侧旧词替换

页面用户侧彻底移除：

- `策略健康`

统一替换为两张独立卡：

- `20日进攻温度`
- `60日结构信任度`

### 13.2 卡片结构

两张卡统一展示：

- 一句结论
- 分数和状态
- 一句解释

### 13.3 顶部摘要

页面顶部在 `今日出手级别` 区域并排摘要两张卡的结论：

- `20日进攻温度：冷，43分。近期进攻反馈降温，但不等于系统失效，今天只降低进攻力度。`
- `60日结构信任度：存疑，39分。主线/角色结构优势不稳定，结论需要打折看。`

### 13.4 冲突场景表达

若当天 `今日出手级别` 仍可做，但 `60日结构信任度 = 存疑`：

- 不自动下调动作级别
- 顶部新增黄色风险提示条

提示语义为：

**今天仍可谨慎跟踪，但这套主线结构的可信度在下降，信任度要打折。**

### 13.5 V1.3 新增页面模块

V1.3 页面新增两类主线增强表达：

- `主线雷达`：展示当日最强 `1-2` 条主线，包含主线强度、候选池占比、涨停数、炸板风险、热榜支撑和代表股。
- `短线情绪`：展示涨停 / 炸板 / 连板 / 昨日强势反馈 / 热榜集中度形成的情绪结论，分为 `高涨 / 可做 / 分歧 / 退潮`。

V1.3 盘中区域统一命名为 `盘中快照辅助`：

- 可以提示 `价格接近观察区`、`偏离过大`、`主线仍有支撑`、`快照低置信度触发`。
- 不允许提示 `分钟级买点正式触发`、`分时承接已确认` 或 `建议买入`。
- 必须明确说明：没有分钟线时，仍需要用户人工确认分时承接。

## 14. V1 最短版

如果只记 V1 当前版本最核心的产品原则，可以直接记这 `10` 条：

1. V1 是标准化生产系统，不是调参工具。
2. 候选池入口固定为全市场统一 `4 / 2 / 2`。
3. 普通用户不再修改入口参数，也不再修改 `TopN`；官方展示固定 `Top30`。
4. `Standard` 是唯一官方生产引擎，`Aggressive` 是折叠式进攻补充观察层。
5. 新总原则是：先由当天市场与机会决定能不能做，再用 20/60 判断该用多大力度相信。
6. 用户侧不再使用“策略健康”，而是拆成 `20日进攻温度` 与 `60日结构信任度`。
7. `20日进攻温度` 调节短期进攻力度，`60日结构信任度` 调节长期结构信任折扣。
8. `今日出手级别` 先看 `市场环境 × 机会质量`，再由 `20日进攻温度 × 60日结构信任度` 联合校准。
9. `今日不做` 与 `系统停用` 必须分开；停用只在连续 `5` 个交易日 `20日冰 + 60日失真` 且当天机会不强时触发。
10. 官方回测只看 `Standard`，`Aggressive` 只保留补充增益率诊断与治理状态。
11. V1.3 基于 `6000` 积分新增主线增强、短线情绪、涨停炸板和热榜证据，但不承诺分钟级买点。
12. V1.3 的盘中能力是 `盘中快照辅助`，不是正式分时买点系统。
