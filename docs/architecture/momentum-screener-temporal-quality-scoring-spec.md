## 2. 问题陈述

当前强势筛选初次评分的六个维度（强度确认、量价配合、趋势位置、题材共振、资金支持、弹性博弈）主要考察股票**当天**的强度。

跨日特征虽已存在（如 `cum_ret_5d`、`strong_days_60d`、MA 均线），但存在两个结构性缺口：

1. **缺时序质量**：只看累计涨跌幅的结果，不看走势的结构。连续温和上行和一根大阳带四根星线可能得分相同，但前者趋势质量远高于后者。

2. **缺变化方向**：题材和个股"在加速还是在减速"没有被量化。题材排名只看当天快照，无法判断它是持续走强还是昙花一现。

3. **缺连续强势运行识别**：连续阳线且收盘价持续站在 MA 上方的股票是趋势质量最高的形态，但在当前评分中分散在多个维度且没有被显式计算。

## 3. 解决方案

在不改变筛选入口和候选池的前提下，在初次评分中新增两个维度：

### 3.1 新增维度一：K 线走势质量 `price_path_quality`

权重 **12%**，总分为 100 分制，由四个子项组成：

| 子项 | 份内权重 | 核心逻辑 |
|------|:---:|------|
| 温和上行结构 | 35% | 将过去 20 日切成远（D[-20:-11]）、中（D[-10:-6]）、近（D[-5:-1]）三段，评估区间涨跌幅、回撤、振幅的协调性 |
| 量能节奏配合 | 25% | 比较近 5 日平均量与前 10 天平均量，结合价格方向判断量价关系 |
| 强度密度 | 20% | 基于 `strong_days_60d` 升级，看最近 3 次大涨的时间间隔是加速还是乏力 |
| 连续强势运行 | 20% | `consecutive_yang` + `ma5_above_days` + `ma10_above_days` 三维综合评估 |

#### 3.1.1 连续强势运行子项详细规则

输入：
- `consecutive_yang`：从今天往回数连续收阳的天数
- `ma5_above_days`：过去 5 日收盘价高于 MA5 的天数
- `ma10_above_days`：过去 10 日收盘价高于 MA10 的天数
- 最近 5 日每根 K 线的 `close / MA5` 比值
- 最近 5 日年化波动率

评分公式：

```
ma5_score    = ma5_above_days / 5 × 0.4
ma10_score   = ma10_above_days / 10 × 0.3
yang_score   = min(consecutive_yang, 5) / 5 × 0.3
combined     = ma5_score + ma10_score + yang_score          # 0.0 ~ 1.0
stability    = 1.0 - min(1.0, 5日年化波动 / 0.05)            # 稳定因子
ratio_bonus  = CMA_ratio > 1.02 → ×1.2, <1.01 → ×0.8         # 依附 vs 驾驭
final_score  = clamp(combined × stability × ratio_bonus, 0, 1)
```

MA 比值附加权重规则：

| 状态 | 定义 | 附加权重 |
|------|------|:---:|
| 驾驭型 | 过去 3 个交易日中有 2 天以上 `close/MA5 > 1.02` 且今日亦满足 | ×1.2 |
| 依附型 | 过去 5 日中超过一半天数 `close/MA5 < 1.01` | ×0.8 |
| 中性 | 其他 | ×1.0 |

### 3.2 新增维度二：题材时序动量 `sector_momentum`

权重 **10%**，由两个子项组成：

| 子项 | 核心逻辑 |
|------|------|
| 排名趋势 | 查缓存中该题材最近 3-5 个交易日的排名，判断持续攀升 / 维持高位 / 从高跌落 / 新进 |
| 扩散/收缩 | 看 strong_count（涨超 5% 的股数）与前几日的对比，判断共振扩散 / 基数扩大 / 龙头聚焦 / 退潮 |

#### 3.2.1 依赖数据

需要在每日强势筛选中将当天各题材的统计快照落盘缓存：

```
sector_name | trade_date | sector_rank | sector_total | strong_count | limit_count | avg_pct
```

第一次启用时前 3-5 个交易日缺少历史缓存，`sector_momentum` 得分设为中性分（不扣不加）。

#### 3.2.2 排名趋势评分规则

查最近 3 个有效交易日的排名 `rank_t, rank_t-1, rank_t-2`：

| 条件 | 得分 |
|------|:---:|
| 排名持续上升（rank 越来越小）且今天首次进入前 10 | 满分 |
| 排名持续上升但未进前 10 | 高 |
| 排名维持在前 5 不变 | 高 |
| 排名维持在 6-10 不变 | 中 |
| 今天才首次出现（前几无缓存） | 中（中性） |
| 排名从高位跌落超过 5 位 | 低 |

#### 3.2.3 扩散/收缩评分规则

| 条件 | 得分 |
|------|:---:|
| strong_count 扩大 + 排名上升 | 高分（共振扩散） |
| strong_count 扩大 + 排名不变 | 中分（基数扩大） |
| strong_count 缩小 + 排名上升 | 中分（龙头聚焦） |
| strong_count 缩小 + 排名下降 | 低分（退潮） |
| 无历史缓存 | 中分 |

### 3.3 权重重分配

原六个维度各降 2-3%，腾出 22% 给两个新维度，总分保持 100 分制：

| 维度 | 旧权重 | 新权重 |
|------|:---:|:---:|
| 强度确认 | 18% | 15% |
| 量价配合 | 18% | 15% |
| 趋势位置 | 12% | 10% |
| 题材共振 | 17% | 14% |
| 资金支持 | 20% | 18% |
| 弹性博弈 | 8% | 8% |
| **K 线走势质量** | — | **12%** |
| **题材时序动量** | — | **10%** |

## 4. 边界条件

1. 新维度**只影响初次评分的排序权重**，不改变候选池入口、筛选门槛和二次决策的收口逻辑。
2. 计算完全基于已有 K 线历史数据，**零额外 API 调用**。题材时序缓存为本地落盘，不需要新数据源。
3. K 线历史不足 20 天时，`price_path_quality` 得分按实际可用天数比例衰减。
4. 题材时序缓存不足 3 天时，`sector_momentum` 得分设为中性分，不扣不加。

## 5. 验收标准

1. 回测验证：使用已有 2026-02-03 ~ 2026-04-08 的历史数据，对比新旧评分的 20 日窗口胜率变化。
2. K 线走势质量得分分布合理：连续阳线 + MA 上方的股票得分应显著高于随机样本。
3. 题材时序动量首次运行时不会因缺少缓存而报错。
4. `Aggressive` 模式同步应用新维度。
