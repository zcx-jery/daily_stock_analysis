## 2. 文档目标

本 PRD 用于把原始 SPEC 拆解成完整、可协作的产品需求，供产品、设计、前端、后端、测试共同理解以下内容：

- 目标用户是谁
- 该功能解决什么问题
- 页面需要提供哪些核心能力
- 用户在 T 日收盘后与 T+1 盘中的操作路径是什么
- 页面状态、推荐逻辑、证据逻辑和降级逻辑如何配合
- 新总闸门如何真正服务于“今天能不能进攻”

## 3. 背景与目标

### 3.1 当前背景

现有强势筛选页已经能完成以下基础能力：

- 从候选池中筛出强势股结果
- 支持 `Standard` 官方主链路与 `Aggressive` 进攻补充观察层
- 展示排序结果与个股详情
- 输出固定 `Top30` 官方展示与明细指标

但从用户真实交易行为看，当前产品仍停留在“给出一堆结果”，还没有真正走到“帮助用户在明天做更少错误的决定”。

### 3.2 本次改版的核心目标

本次新增的 `二次决策` 能力，不是为了替代现有筛选页，而是为了把“筛选结果”进一步收口成“明日可执行的候选顺序与信号辅助”，目标包括：

- 帮用户从候选股中明确谁更值得看、谁更值得等买点
- 帮用户建立对推荐顺序的信任，而不是只看到一堆分数
- 帮用户减少在买点未形成时提前追高的错误
- 帮用户在次日开盘后 `60` 分钟内更稳定地形成 `买 / 不买` 决定
- 把旧的“策略健康”单一心智，拆成更清晰的“20日进攻许可 + 60日主线可信度”
- 在 `6000` 积分权限范围内，把产品从单股排序升级为 `主线识别 + 短线情绪 + 题材验证 + 回测诊断`，但不把实时快照包装成分钟级买点。
- 回测主胜率改为 `短线延续合格率`：`T+1 收盘价 > T+1 开盘价`，且 `T+2 最高价 > T+1 收盘价`，优先验证“方向是否选对”，再用利润窗口与回撤验证“执行是否舒服”。

## 4. 目标用户

### 4.1 核心用户

- A 股短线交易用户
- 会看盘、会看强势股与主线
- 还不会系统化选股与排序
- 每天收盘后会从候选池收敛到 `2-5` 只股票
- 次日有明确的短线执行需求

### 4.2 典型能力边界

这类用户通常：

- 能看懂哪些票强
- 能大致收敛到 `3` 只左右
- 但分不清哪只更值得买
- 也不清楚为什么自己该等、该放弃、该观察

### 4.3 典型错误行为

- 买点未触发时提前买入
- 看见主线强就直接追高
- `3` 只候选里买了次优票
- 今天其实应观察或不做，却仍然硬做

## 5. 核心问题陈述

### 5.1 核心问题

用户当前最大的问题不是“没有候选票”，而是：

`已经能把候选池收敛到 3 只左右，但分不清谁更值得买、为什么更值得买、明天应该怎么等买点。`

### 5.2 当前产品的主要缺口

- 缺少推荐顺序与仓位角色解释
- 缺少为什么选它、不选它的透明解释
- 缺少明日是否适合出手的总判断
- 缺少主线、买点、证据三者之间的闭环
- 缺少盘中信号失真时的低置信度降级机制
- 缺少把“今天能不能做”和“这套主线值不值得信”分开表达的清晰产品心智

## 6. 产品定位

本产品的定位不是传统选股器，也不是自动交易系统，而是：

`一个先排序、再给次日执行信号的两阶段助手。`

### 6.0.1 二次决策角色重构（2026-04-27 冻结）

随着主排序引擎升级为“初筛后全候选统一重评分”，二次决策的定位同步收口为：

- **不再负责重新定义谁更强**
- **只负责把正式排序结果收口成可执行官方结论**

因此，二次决策的正式职责是：

1. 组合收口：从完整排序集中选择 `主仓 / 次仓 / 观察仓`
2. 动作收口：判断今天是 `强烈可做 / 可正常出手 / 谨慎出手 / 仅观察 / 今日不做`
3. 执行收口：输出买点提示、触发条件、追高上限和失效位
4. 解释收口：说明为什么入选、为什么落选
5. 风险收口：在总闸门、买点、角色冲突或数据降级时诚实降级

二次决策不再承担：

- 第二套正式重排序引擎
- 用解释因子推翻主排序
- 仅基于页面 Top30 子集重做官方结论

### 6.1 第一阶段：T 日收盘后二次决策

系统在现有强势筛选结果基础上，完成以下工作：

- 识别 `1-2` 条主线
- 为每条主线选择 `龙头核心 / 前排换手 / 观察备选`
- 生成默认 `主仓 / 次仓 / 观察仓`
- 给出今日出手级别与一句理由
- 解释为什么入选、为什么落选
- 提供证据区与历史相似案例

### 6.2 第二阶段：T+1 盘中信号辅助

系统不改变前一晚的排序，只在次日早盘观察是否形成可执行信号：

- 哪只票接近或进入买点
- 哪只票掉队
- 是否进入低置信度
- 到 `60` 分钟内是否形成 `建议买 / 不建议买`

## 7. 产品原则

- 系统给出明确排序与强烈倾向，但不替用户完成最终买卖执行
- 排序是系统正式判断结果，用户默认不能手改
- 页面必须能解释“为什么是这个顺序”
- 页面必须允许“今天不给满 3 只”
- 页面必须在关键不确定时诚实降级，而不是硬给结论
- 官方生产基线必须固定：统一入口、统一展示数量、统一回测口径，不能再被用户调参改写
- `Standard` 是唯一官方主结论；`Aggressive` 只作为折叠式进攻补充观察层存在
- 新总原则是：
  - **先判断今天能不能进攻，再判断这套主线值不值得信**

## 8. 范围界定

### 8.1 Phase 1 在做什么

- 基于现有强势筛选页新增 `二次决策`
- 支持主线识别、默认组合、证据区、行动清单、盘中信号
- 聚焦 `T 日筛股 -> T+1 买点辅助`

### 8.2 Phase 1 不做什么

- 不做自动交易
- 不做完整卖出系统
- 不开放入口阈值和 `TopN` 给普通用户调节
- 不覆盖港股、美股、中线策略
- 不把产品做成教学平台
- 不把 `Aggressive` 做成平行官方组合或平行官方回测

### 8.3 V1 官方基线

- 市场范围固定为：`主板 + 创业板 + 科创板`
- 官方入口阈值固定为：`最小涨幅 4% / 最小成交额 2亿 / 最小换手率 2%`
- 官方页面展示与导出固定为：`Top30`
- 二次决策始终基于 `完整排序集` 收口，而不是基于页面当前展示数量继续挑票
- 官方回测只回放 `Standard 官方链路`
- 主排序负责给出正式强度顺序；二次决策只负责组合与动作，不再作为独立重排层

### 8.4 V1.3 主线增强范围

V1.3 面向 `6000` 积分数据权限，新增以下产品能力：

- 用 `ths_member` 建立股票到题材 / 概念 / 主线的映射。
- 用 `limit_list_d` 和 `stk_limit` 补强涨停、炸板、连板、涨跌停边界和追高风险判断。
- 用 `ths_hot` 作为热门股、热门概念和关注度的辅助证据。
- 在总闸门中新增 `短线情绪`，用于判断当天是否适合继续奖励强势股。
- 在回测中新增失败归因，区分主线、情绪、角色、价格位置和总闸门问题。

V1.3 明确不做：

- 不做分钟级正式买点触发。
- 不做分时均线 / VWAP 承接确认。
- 不把 `realtime_quote` 快照输出包装成高置信度盘中买点。

## 9. 页面结构

`二次决策` 视图继续放在现有强势筛选页内，不另起产品入口。

### 9.1 页面区块

页面从上到下分为：

1. 今日出手级别
2. `20日进攻许可` 与 `60日主线可信度`
3. 主线识别与默认组合
4. 推荐股卡片区
5. 候选池落选解释区
6. 证据区
7. 明日行动清单
8. `Aggressive` 进攻补充观察层（按条件提示展开）
9. V1.3 `主线雷达`、`短线情绪` 与 `盘中快照辅助`

### 9.2 今日出手级别

展示内容：

- 五档状态：
  - `强烈可做`
  - `可正常出手`
  - `谨慎出手`
  - `仅观察`
  - `今日不做`
- 一句理由
- 顶部并排摘要：
  - `20日进攻许可：...`
  - `60日主线可信度：...`

### 9.3 20日进攻许可卡

目标：

- 回答“最近还能不能正常进攻”

展示结构：

- 一句结论
- 分数和状态
- 一句解释

用户侧状态词：

- `可进攻`
- `恢复中`
- `暂停进攻`

### 9.4 60日主线可信度卡

目标：

- 回答“这套主线识别框架最近值不值得信”

展示结构：

- 一句结论
- 分数和状态
- 一句解释

用户侧状态词：

- `可信`
- `恢复中`
- `存疑`

若当天仍可做但 `60日主线可信度 = 存疑`：

- 不自动下调动作级别
- 顶部新增黄色风险提示条

### 9.5 主线识别区

目标：

- 明确告诉用户今天在看哪 `1-2` 条主线
- 让用户先理解“市场主攻方向”，再看个股

输出内容：

- 主线名称
- 主线综合强度
- 主线是否达到 `极强`
- 每条主线的代表股

### 9.6 默认组合区

展示系统正式排序结果：

- `主仓`
- `次仓`
- `观察仓`

组合原则：

- `主仓` 默认取正式主排序结果中的第一优先票
- 只有当第一优先票命中 `硬阻断` 时，才允许降为 `次仓` 或 `观察仓`
- `次仓` = 保持前排强度前提下，更适合补强组合或承担进攻弹性的那只
- `观察仓` = 主线确认票或高强度挑战者
- 允许只输出 `1-2` 只，不强凑第三只

硬阻断包括但不限于：

- 买点极不清晰
- 当前总闸门不允许正式执行
- 与已选票在主线和角色上重复过强
- 风险红线明显超标

除硬阻断外，角色、买点、主题地位等因素只允许做“小幅修正”，不能推翻正式主排序。

### 9.7 推荐股卡片

每张卡片优先回答：

`为什么它适合放在这个仓位`

卡片展示顺序：

1. 主线视角
2. 主线地位 + 明天买点 / 执行理由
3. 组合作用

### 9.8 落选解释区

所有未入选票都要给出 `一个主因`，用于提升透明度。

主因优先级：

- `非主线 / 主线过弱`
- `主线内名次不够`
- `角色重复`
- `买点不清晰`
- `当前总闸门不支持`
- `近期验证弱`

### 9.9 证据区

证据区不抢主结论路径，核心任务是增强信任。

展示顺序：

1. 这条主线最近值不值得做
2. 为什么今天系统敢给这个结论
3. 每只推荐股最像的历史案例

### 9.10 明日行动清单

只有 `Standard 官方结论` 在以下两档时才生成：

- `强烈可做`
- `可正常出手`

清单分三段：

- `开盘前`
- `开盘后 30 分钟`
- `开盘后 60 分钟内`

### 9.11 Aggressive 进攻补充观察层

- `Aggressive` 默认放入折叠区，不与 `Standard` 并列展示主结论
- 只有当 `Aggressive` 补出 `不在 Standard 官方 Top3` 内的新票，且该票同时满足 `高进攻度 + 买点相对清晰 + 不推翻 Standard 总闸门` 时，页面才提示“可展开查看”
- `高进攻度` 定义为：`弹性高 + 主线里有地位 + 风险不过红线`
- 风险红线至少排除：`明显追高 / 没有买点区间 / 已接近失效位`
- `买点相对清晰` 对 `Aggressive` 比 `Standard` 宽半档：允许 `等待触发` 进入补充观察，但必须已经具备 `买点区间 + 触发条件 + 非明显追高`
- `Aggressive` 只展示新增补充票，最多 `2` 只，按 `进攻弹性` 排序
- 每张 `Aggressive` 卡片展示：`进攻理由 / 主线角色 / 买点区间 / 触发条件 / 失效位`
- `Aggressive` 可进入独立的 `进攻观察清单`，但必须与 `Standard 官方行动清单` 分开展示，并持续标注：`仅补充观察，不纳入官方组合`
- 若 `Standard` 判定为 `仅观察` 或 `今日不做`，`Aggressive` 仍可显示，但只能以折叠入口方式显示，并明确写出：`有进攻补充观察机会，但不改变官方结论`
- 即使 `Aggressive` 补充票次日先触发，也不能升格替代 `Standard` 的官方顺序

### 9.12 V1.3 主线雷达与盘中快照辅助

V1.3 页面新增 `主线雷达`：

- 展示当日最强 `1-2` 条主线。
- 展示主线强度分、涨停数、炸板风险、候选池占比、热榜支撑和代表股。
- 若主线不清晰，必须明确显示 `主线不清晰`，不强行归因。

V1.3 页面新增 `短线情绪`：

- 输出 `高涨 / 可做 / 分歧 / 退潮` 四档。
- 展示涨停、炸板、连板、昨日强势反馈和热榜集中度的关键依据。

V1.3 盘中模块统一命名为 `盘中快照辅助`：

- 可以提示价格是否接近观察区、是否偏离过大、主线是否仍有快照支撑。
- 必须展示置信度与数据时间。
- 必须提示“仍需人工确认分时承接”。

## 10. 新总闸门需求

### 10.1 总体框架

`今日出手级别` 先由：

- `市场环境 × 机会质量`

决定主矩阵，再由：

- `20日进攻许可`

封顶。

`60日主线可信度` 不再直接决定当天动作级别，而是只做结构信任提示。

### 10.2 20日进攻许可

目标：

- 判断最近还能不能正常进攻

核心口径：

- 买点先触发
- 再打出角色对应利润窗口

角色门槛：

- 龙头核心：`>= 2.0%`
- 前排换手：`>= 2.5%`
- 观察备选：`>= 1.5%`

状态分档：

- `可进攻 >= 55%`
- `恢复中 >= 40%`
- 其余为 `暂停进攻`

样本门槛：

- `可进攻` 至少 `5` 个有效样本
- `恢复中` 至少 `3` 个有效样本

### 10.3 60日主线可信度

目标：

- 判断主线识别框架最近值不值得信

核心口径：

- 最强核心票是否落在第一主线
- 第一主线是否覆盖次日强票 `Top3`
- `Top5` 覆盖只做轻加分

单日评分：

- 最强核心命中第一主线：`0.6`
- 第一主线覆盖次日强票 `Top3` 至少 `2` 只：`0.4`
- 第一主线覆盖次日强票 `Top5` 至少 `3` 只：`+0.1`
- 单日总分封顶 `1.0`

分档：

- `可信 >= 0.60`
- `恢复中 >= 0.45`
- 否则 `存疑`

样本门槛：

- `可信` 至少 `12` 个有效样本
- `恢复中` 至少 `8` 个有效样本

### 10.4 市场环境

核心问题：

**市场今天愿不愿意继续为强势股付溢价。**

样本池：

- `昨日二次决策 Top3` 看核心溢价
- `昨日候选池 Top10` 看广度溢价

核心有溢价：

- 昨日 `Top3` 中至少 `1` 只今天先触发买点
- 且 `T+1/T+2 利润窗口 >= 2.0%`

广度达标：

- 昨日 `Top10` 命中率 `>= 30%`
- 且平均利润窗口 `>= 2.0%`

三档：

- `强`
- `中等`
- `弱`

判定规则：

- `强` = 核心有溢价 + 广度达标
- `中等` = 只好一边
- `弱` = 两边都不行

### 10.5 机会质量

核心问题：

**今天系统手上的这批票，是否足够适合出手。**

判断顺序：

1. 买点清晰度
2. 默认组合盈亏比
3. 主线集中度

买点清晰度分档：

- `3只清晰 = 强`
- `2只清晰 = 中上`
- `1只清晰 = 中`
- `0只清晰 = 弱`

主仓最低盈亏比门槛：

- `预期利润空间 >= 预期失效空间的 1.5 倍`

主线集中度：

- 默认组合至少 `2` 只来自第一主线

边界规则：

- `3只清晰`
  - 默认 `强`
  - 只有主仓盈亏比不过线时才下调
- `2只清晰`
  - 默认 `中上`
  - 只有“主仓盈亏比过线 + 主线集中度达标”时才升到 `强`
- `1只清晰`
  - 默认 `中`
  - 主仓盈亏比过线则维持 `中`
  - 不过线则降为 `弱`
- `0只清晰`
  - 固定 `弱`
  - 不允许被抬高

## 11. 今日出手级别矩阵

基础主矩阵如下：

| 市场环境 \\ 机会质量 | 强 | 中上 | 中 | 弱 |
| --- | --- | --- | --- | --- |
| 强 | 强烈可做 | 可正常出手 | 谨慎出手 | 仅观察 |
| 中等 | 可正常出手 | 谨慎出手 | 仅观察 | 今日不做 |
| 弱 | 谨慎出手 | 仅观察 | 今日不做 | 今日不做 |

再由 `20日进攻许可` 封顶：

- `可进攻`
  - 不压级
- `恢复中`
  - 最高封顶到 `可正常出手`
- `暂停进攻`
  - `市场环境强 + 机会质量强` 时，最高到 `谨慎出手`
  - 若只强一边，最多 `仅观察`
  - 若两边都不强，直接 `今日不做`

## 12. 停用与恢复

### 12.1 今日不做

`今日不做` 是单日结论，不等于系统长期停用。

### 12.2 系统停用

`系统停用` 只有在以下条件下触发：

- 连续 `5` 个交易日
- `20日进攻许可 = 暂停进攻`
- `60日主线可信度 = 存疑`

### 12.3 退出停用

退出停用的条件：

- `20日进攻许可` 回到 `恢复中`
- 且当天 `市场环境` 不是 `弱`

退出停用后，只恢复到：

- `仅观察`
- 或最多 `谨慎出手`

### 12.4 恢复正常

当 `20日进攻许可 = 可进攻` 时，恢复到：

- `可正常出手`

### 12.5 重新允许强烈可做

只有同时满足以下条件，才允许重新给 `强烈可做`：

- `20日进攻许可 = 可进攻`
- `市场环境 = 强`
- `机会质量 = 强`

## 13. Aggressive 补充观察层与回测治理

### 13.1 官方回测口径

- 官方回测只回放 `Standard 官方链路`
- 回放链路固定为：`统一入口 4 / 2亿 / 2% -> 候选池 -> 全量评分排序 -> Standard 二次决策 -> 官方 Top3 / 今日出手级别 / T+1/T+2 结果`
- `Aggressive` 不再作为第二套官方回测画像运行

### 13.2 Aggressive 诊断指标

- `Aggressive` 只保留 `补充增益率` 诊断，不进入官方胜率口径
- `补充增益率` 定义为：`Aggressive` 补充票不在 `Standard 官方 Top3` 中，且其后续表现优于 `Standard 观察仓` 或未入选边界票的比例

### 13.3 Aggressive 治理状态

- 内部保留完整四态：`正常 / 待校准 / 观察恢复 / 完全恢复`
- 用户侧只显示简化三态：`正常 / 增益有限 / 恢复中`
- 当用户侧显示 `增益有限` 时，配套解释统一为：`当前进攻补充层近期有效增益偏少，仅保留观察参考。`

### 13.4 Aggressive 降级与恢复

- 当 `20日补充增益率 < 20%` 且 `60日补充增益率 < 25%` 时，`Aggressive` 进入 `待校准`
- 进入 `待校准` 后，页面双重降级：`入口文案弱化 + 不再主动提示可展开查看`，但仍允许用户手动展开
- 当 `20日补充增益率 >= 25%` 时，进入 `观察恢复`
- 当 `60日补充增益率 >= 30%` 时，进入 `完全恢复`

## 14. 用户旅程

### 13.1 T 日收盘后

用户进入强势筛选页后，希望先看到：

- 今天能不能做
- 在做哪条主线
- 官方默认组合是什么
- 为什么是这个顺序

### 13.2 T+1 开盘前

用户希望明确：

- 明天先盯哪一只
- 哪只票掉队要先排除
- 哪些信号出现时才值得考虑出手

### 13.3 T+1 开盘后 60 分钟内

用户希望系统最终收口成：

- `建议买`
- `不建议买`
- `保留观察但不建议执行`

## 15. 成功标准

- 用户能在一页内回答：
  - 今天该不该做
  - 为什么给这 `1-3` 只
  - 为什么没选其他票
  - 每只票怎么等买点
  - 这套判断凭什么值得信
- 页面不再向用户暴露“策略健康”旧词，而是明确展示：
  - `20日进攻许可`
  - `60日主线可信度`
- `60日主线可信度 = 存疑` 时，若当天仍可做，页面必须用黄色风险提示表达“今天可做，但结构信任度下降”。
- 官方结果必须锚定在统一入口 `4 / 2亿 / 2%` 与固定 `Top30` 基线上，不能再因页面展示数量或画像切换而改变官方主结论。
- 用户必须能明确理解：`Standard` 是官方结论，`Aggressive` 只是折叠式进攻补充观察，不参与官方排序与官方回测。
- 用户在系统显示“未触发买点”时提前买入的次数下降。
- 用户在开盘后 `60` 分钟内做出明确 `买 / 不买` 决定的天数明显上升。
