# 次日强势股筛选 V1 评分规则

## 1. 文档信息

- 文档名称：次日强势股筛选 V1 评分规则
- 所属系统：`daily_stock_analysis`
- 适用版本：`V1`
- 文档类型：规则基线文档
- 当前状态：草案 V1
- 关联文档：
  - [次日强势股筛选产品方案](d:\AI_Project\_remote_edit\daily_stock_analysis\docs\architecture\momentum-screener-product-plan.md)
  - [次日强势股筛选 PRD](d:\AI_Project\_remote_edit\daily_stock_analysis\docs\architecture\momentum-screener-prd.md)

## 2. 文档目的

本文档用于固化 `V1` 版本的评分规则，作为后续产品实现、回测验证和版本升级的统一基线。

本文档解决的问题：

- `V1` 到底评哪些维度
- 每个维度具体如何打分
- 每个子项的分档和分值如何定义
- 哪些是正向加分项，哪些是风险扣分项

## 3. V1 版本边界

`V1` 是收盘后运行的基础版筛选器，基于 `Tushare 2000分` 可用数据设计。

### 3.1 V1 目标

1. 从今日涨幅大于阈值 `N` 的股票中构建候选池
2. 对候选池进行收盘后多维评分
3. 输出明日重点关注的 `Top X`

### 3.2 V1 不解决的问题

以下能力不属于 `V1`：

- 盘中分时强弱判断
- 封板过程实时跟踪
- 回封质量判断
- 实时尾盘承接分析

这些能力属于后续 `V2`。

### 3.3 V1 依赖的核心数据

- `daily`
- `stock_basic`
- `daily_basic`
- `moneyflow`
- `top_list`
- `stk_limit`

## 4. 候选池硬过滤规则

评分前，先执行候选池过滤。

默认建议：

- 今日涨幅 `>= N`
- 排除 `ST/*ST`
- 排除长期停牌
- 排除上市时间过短的新股
- 默认只看主板
- 设置最低成交额门槛
- 设置最低换手率门槛

推荐默认值：

- `min_change_pct = 7`
- `min_amount = 3亿`
- `min_turnover = 3%`
- `exclude_st = true`
- `main_board_only = true`

说明：

- 候选池规则不计入评分
- 只有通过硬过滤的股票才进入评分环节

## 5. 评分总结构

### 5.1 基础总分

```text
基础总分
= 强势确认质量(20)
+ 量价结构(20)
+ 趋势位置与形态(15)
+ 板块题材共振(20)
+ 资金承接质量(15)
+ 弹性与股性(10)
```

### 5.2 最终总分

```text
最终总分 = 基础总分 - 风险修正(0~20)
```

### 5.3 维度分值结构

| 维度 | 分值 |
|---|---:|
| 强势确认质量 | 20 |
| 量价结构 | 20 |
| 趋势位置与形态 | 15 |
| 板块题材共振 | 20 |
| 资金承接质量 | 15 |
| 弹性与股性 | 10 |
| 风险修正 | 0 ~ -20 |

## 6. 强势确认质量 20

目的：判断今天是不是“真强”。

### 6.1 今日涨幅强度 6

计算口径：`pct_chg`

| 条件 | 分数 |
|---|---:|
| `>= 9.7%` | 6 |
| `9.0% ~ 9.69%` | 5 |
| `8.0% ~ 8.99%` | 4 |
| `7.0% ~ 7.99%` | 3 |
| `< 7.0%` | 0 |

说明：

- 该项只衡量今天的强势程度
- 该项不能单独代表次日延续性

### 6.2 收盘位置 5

计算口径：

```text
close_position = (close - low) / (high - low)
```

特殊规则：

- 若 `high == low` 且当日收涨，直接记 `5分`

> 实现说明：V1 代码中未实现此特殊规则。一字涨停板场景极罕见，对评分影响可忽略。

| 条件 | 分数 |
|---|---:|
| `>= 0.90` | 5 |
| `0.80 ~ 0.89` | 4 |
| `0.65 ~ 0.79` | 3 |
| `0.50 ~ 0.64` | 2 |
| `< 0.50` | 0 |

说明：

- 越接近日内高点，说明承接越强

### 6.3 涨停接近度 4

计算口径：

```text
limit_proximity = close / up_limit
```

| 条件 | 分数 |
|---|---:|
| `>= 99.5%` | 4 |
| `98.5% ~ 99.49%` | 3 |
| `97.0% ~ 98.49%` | 2 |
| `95.0% ~ 96.99%` | 1 |
| `< 95.0%` | 0 |

说明：

- 该项是 `V1` 对“封板质量”的代理

### 6.4 K线实体强度 5

计算口径：

```text
body_ratio = abs(close - open) / (high - low)
```

特殊规则：

- 若 `high == low` 且 `close > open`，直接记 `5分`

> 实现说明：V1 代码中未实现此特殊规则。一字涨停板场景极罕见，对评分影响可忽略。

| 条件 | 分数 |
|---|---:|
| `>= 0.70` | 5 |
| `0.55 ~ 0.69` | 4 |
| `0.40 ~ 0.54` | 3 |
| `0.25 ~ 0.39` | 2 |
| `< 0.25` | 0 |

说明：

- 大实体阳线优于冲高回落的小实体

## 7. 量价结构 20

目的：判断上涨是否具有交易质量。

### 7.1 量比 6

计算口径：`volume_ratio`

| 条件 | 分数 |
|---|---:|
| `1.5 ~ 3.0` | 6 |
| `1.2 ~ 1.49` | 5 |
| `3.01 ~ 4.0` | 4 |
| `1.0 ~ 1.19` | 3 |
| `4.01 ~ 5.0` | 2 |
| `< 1.0` 或 `> 5.0` | 0 |

说明：

- 最优区间是“有热度但不过热”

### 7.2 换手率 6

计算口径：`turnover_rate`

| 条件 | 分数 |
|---|---:|
| `3% ~ 15%` | 6 |
| `2% ~ 2.99%` | 5 |
| `15.01% ~ 20%` | 4 |
| `1% ~ 1.99%` | 3 |
| `20.01% ~ 25%` | 2 |
| `< 1%` 或 `> 25%` | 0 |

说明：

- 换手太低，通常没有足够合力
- 换手太高，通常意味着高分歧

### 7.3 成交额分位 4

计算口径：

- 在当日候选池内按 `amount` 排名
- 使用候选池相对分位

| 条件 | 分数 |
|---|---:|
| 前 `20%` | 4 |
| 前 `20% ~ 40%` | 3 |
| 前 `40% ~ 70%` | 2 |
| 后 `30%` | 0 |

说明：

- `V1` 先采用相对排名，不采用绝对阈值打分

### 7.4 放量质量 4

计算口径：

```text
volume_expand = amount / avg(amount_5)
```

其中 `avg(amount_5)` 为前 5 个交易日平均成交额。

| 条件 | 分数 |
|---|---:|
| `1.5 ~ 3.0` | 4 |
| `1.2 ~ 1.49` | 3 |
| `3.01 ~ 4.0` | 2 |
| `1.0 ~ 1.19` | 1 |
| `< 1.0` 或 `> 4.0` | 0 |

说明：

- 适度放量优于缩量偷拉
- 极端爆量不视为高质量放量

## 8. 趋势位置与形态 15

目的：判断股票处在启动、主升还是衰竭阶段。

### 8.1 均线结构 5

计算口径：

- `MA5`
- `MA10`
- `MA20`

| 条件 | 分数 |
|---|---:|
| `MA5 > MA10 > MA20` 且 `close > MA5` | 5 |
| `MA5 > MA10` 且 `close > MA10` | 4 |
| `close > MA5`，但均线未完全多头 | 3 |
| `close > MA20`，结构一般 | 2 |
| `close <= MA20` | 0 |

### 8.2 突破结构 5

计算口径：

- `prev_20d_high`：前 20 个交易日最高价，不含今日
- `prev_60d_high`：前 60 个交易日最高价，不含今日

| 条件 | 分数 |
|---|---:|
| `close > prev_20d_high` 或 `high > prev_60d_high` | 5 |
| `close` 距 `prev_20d_high` 在 `1%` 内 | 4 |
| `close` 距 `prev_20d_high` 在 `3%` 内 | 3 |
| 有平台整理但未接近突破 | 1 |
| 明显仍在平台中部 | 0 |

### 8.3 连续强势状态 5

计算口径：

- 观察近 5 个交易日累计涨幅
- 统计近 5 个交易日上涨天数

| 条件 | 分数 |
|---|---:|
| 近 5 日累计涨幅 `>= 15%`，且至少 `3` 日上涨 | 5 |
| 近 5 日累计涨幅 `10% ~ 14.99%`，且至少 `3` 日上涨 | 4 |
| 近 5 日累计涨幅 `5% ~ 9.99%` | 3 |
| 仅今日单日爆发，前 4 日无明显强势 | 1 |
| 近 5 日整体走弱 | 0 |

说明：

- 该项主要压低单日脉冲股

## 9. 板块题材共振 20

目的：判断个股是否站在市场主线中。

### 9.0 V1 固定数据口径

`V1` 的板块题材共振口径在本版本中固定如下，不再使用“概念题材、多标签热点池、人工题材映射”作为主口径：

#### 主口径

- 使用 **申万一级行业** 作为唯一板块口径
- 每只股票在 `V1` 中只归属一个主板块
- 不在 `V1` 中引入多概念叠加评分

#### 推荐接口

- `index_classify`
- `index_member_all`
- `index_daily`
- `daily`

#### 固定规则

1. 使用 `index_member_all` 将股票映射到申万一级行业
2. 使用 `index_daily` 获取申万一级行业当日涨跌幅
3. 使用 `daily` 统计同一申万一级行业内的涨停数、大涨家数、强势梯队和个股地位
4. 若个股存在多层行业映射，`V1` 统一只取申万一级行业

#### 回退规则

若某只股票在当日无法正确映射到申万一级行业：

- 该股的板块题材共振维度默认记中性低分
- 不尝试在 `V1` 中临时切换到概念题材口径

默认回退建议：

- `板块涨幅排名`：`2分`
- `板块涨停/大涨家数`：`1分`
- `板块梯队完整度`：`1分`
- `个股板块地位`：`1分`

说明：

- 这样做的目的不是追求题材解释最丰富，而是保证 `V1` 规则稳定、可复现、可回测
- 概念题材、多热点标签、最强题材识别属于 `V1.5 / V2` 可扩展能力，不进入 `V1` 主规则

### 9.1 板块涨幅排名 5

计算口径：

- 取所属 **申万一级行业** 当日涨幅
- 计算其在全市场申万一级行业中的排名

| 条件 | 分数 |
|---|---:|
| 前 `10%` | 5 |
| 前 `10% ~ 20%` | 4 |
| 前 `20% ~ 35%` | 3 |
| 前 `35% ~ 50%` | 2 |
| 后 `50%` | 0 |

### 9.2 板块涨停/大涨家数 6

计算口径：

- V1 基于日线数据，不区分涨停与大涨，统一以 `pct_chg >= 7%` 作为强势股计数
- 同一申万一级行业内统计强势股数量

| 条件 | 分数 |
|---|---:|
| `>= 6` 只强势股 | 6 |
| `4 ~ 5` 只强势股 | 5 |
| `2 ~ 3` 只强势股 | 3 |
| 只有本股明显强 | 1 |
| 板块无联动 | 0 |

> V1.5 规划：引入 `limit_list_d` 后区分涨停与大涨，恢复原始分档标准。

### 9.3 板块梯队完整度 4

计算口径：

- 在同一申万一级行业内判断是否同时存在：
  - 龙头股
  - 中位跟随
  - 低位扩散

| 条件 | 分数 |
|---|---:|
| 有明显龙头，且有中位/后排联动 | 4 |
| 有龙头和少量跟随 | 3 |
| 只有少量个股同步上涨 | 2 |
| 基本孤立 | 0 |

### 9.4 个股板块地位 5

计算口径：

- 在所属申万一级行业内按以下代理因子综合排序：
  - `pct_chg`
  - `amount`
  - `close_position`

| 条件 | 分数 |
|---|---:|
| 板块龙头 / 前 `1~2` 名 | 5 |
| 板块前排 / 前 `3~5` 名 | 4 |
| 板块中位 | 2 |
| 板块后排 | 0 |

## 10. 资金承接质量 15

目的：判断今天是谁在买、买得是否稳定。

### 10.1 主力净流入绝对额 6

计算口径：

- 使用 `moneyflow` 中主力净流入金额
- 在候选池内排序

| 条件 | 分数 |
|---|---:|
| 候选池前 `10%` | 6 |
| 前 `10% ~ 25%` | 5 |
| 前 `25% ~ 50%` | 3 |
| 后 `50%` 但仍为正 | 1 |
| 净流出 | 0 |

### 10.2 主力净流入强度 4

计算口径：

```text
main_inflow_ratio = 主力净流入额 / amount
```

| 条件 | 分数 |
|---|---:|
| `>= 5%` | 4 |
| `3% ~ 4.99%` | 3 |
| `1% ~ 2.99%` | 2 |
| `0 ~ 0.99%` | 1 |
| `< 0` | 0 |

### 10.3 龙虎榜质量 3

计算口径：

- 是否上榜
- 净买入额
- 上榜原因是否健康

| 条件 | 分数 |
|---|---:|
| 上榜且净买入明显为正 | 3 |
| 上榜但中性 | 2 |
| 未上榜 | 1 |
| 上榜且明显净卖出 | 0 |

说明：

- 未上榜不重罚
- 该项只作为增强项，不主导总分

### 10.4 价资一致性 2

计算口径：

- 今日价格强弱与主力净流入方向是否一致

| 条件 | 分数 |
|---|---:|
| 涨幅强且净流入为正 | 2 |
| 涨幅中等且净流入为正，或涨幅强但净流入很弱 | 1 |
| 涨幅强但净流出 | 0 |

## 11. 弹性与股性 10

目的：判断如果继续走强，后续空间是否足够。

### 11.1 流通市值弹性 4

计算口径：`circ_mv`

`V1` 先采用主板静态口径。

| 条件 | 分数 |
|---|---:|
| `30亿 ~ 150亿` | 4 |
| `15亿 ~ 30亿` 或 `150亿 ~ 300亿` | 3 |
| `300亿 ~ 500亿` | 2 |
| `< 15亿` 或 `> 500亿` | 0 |

说明：

- `V1` 不做动态市场风格适配

### 11.2 历史股性 4

计算口径：

- 观察近 60 个交易日
- 统计 `pct_chg >= 7%` 的交易日次数
- 统计是否出现过涨停

| 条件 | 分数 |
|---|---:|
| 近 60 日有 `>= 1` 次涨停，或 `>= 3` 次 `7%+` 大阳线 | 4 |
| 有 `2` 次 `7%+` 大阳线 | 3 |
| 有 `1` 次 `7%+` 大阳线 | 2 |
| 无明显历史强势记录 | 0 |

### 11.3 短线辨识度 2

计算口径：

- V1 使用近 **60 个交易日** 数据代理辨识度（而非 20 日），统计是否频繁出现在强势池中、是否有龙虎榜或明显市场关注痕迹

| 条件 | 分数 |
|---|---:|
| 近 60 日有持续强势记录，市场辨识度高 | 2 |
| 偶发强势，辨识度一般 | 1 |
| 基本无辨识度 | 0 |

> V1.5 规划：引入更细粒度的短期辨识度模型，可区分近 20 日与近 60 日的活跃度差异。

## 12. 风险修正 0 到 -20

目的：避免“今天最强、明天最危险”的股票排到前面。

风险修正独立计算，不并入正向评分。

### 12.1 长上影 / 冲高回落

计算口径：

```text
upper_shadow_ratio = (high - max(open, close)) / (high - low)
```

| 条件 | 扣分 |
|---|---:|
| `>= 0.40` | -5 |
| `0.30 ~ 0.39` | -4 |
| `0.20 ~ 0.29` | -2 |
| `< 0.20` | 0 |

### 12.2 爆量滞涨

计算口径：

- `amount / avg(amount_5)` 明显偏高
- 但 `pct_chg` 和 `close_position` 不够强

| 条件 | 扣分 |
|---|---:|
| 放量 `> 4倍` 且收盘位置差 | -4 |
| 放量 `3~4倍` 且强度一般 | -3 |
| 明显爆量但仍封死或收强 | -1 |
| 无明显问题 | 0 |

### 12.3 尾盘走弱

`V1` 无分时数据，先使用 `close_position` 作为代理。

| 条件 | 扣分 |
|---|---:|
| `close_position < 0.50` | -4 |
| `0.50 ~ 0.64` | -2 |
| `>= 0.65` | 0 |

### 12.4 高位连续加速

计算口径：

- 近 3 日累计涨幅
- 近 5 日累计涨幅

| 条件 | 扣分 |
|---|---:|
| 近 3 日 `>= 20%` 或近 5 日 `>= 30%` | -5 |
| 近 3 日 `15% ~ 19.99%` | -3 |
| 近 5 日 `20% ~ 29.99%` | -2 |
| 无明显连续加速 | 0 |

### 12.5 板块退潮

计算口径：

- 个股很强，但板块整体涨幅不高
- 板块联动弱
- 板块内跟随不足

| 条件 | 扣分 |
|---|---:|
| 个股强但板块明显不跟 | -5 |
| 板块仅少量跟随 | -3 |
| 板块中性 | -1 |
| 板块强共振 | 0 |

### 12.6 资金背离

计算口径：

- 今日涨幅强，但主力净流入为负

| 条件 | 扣分 |
|---|---:|
| 涨幅强且净流出明显 | -4 |
| 涨幅强但小幅净流出 | -2 |
| 价资基本一致 | 0 |

### 12.7 龙虎榜偏兑现

计算口径：

- 上榜且净卖出明显

| 条件 | 扣分 |
|---|---:|
| 上榜且净卖出明显 | -3 |
| 上榜但偏中性 | -1 |
| 未上榜或净买入 | 0 |

## 13. 展示结果建议

页面或接口建议同时展示以下字段：

- `continuation_score`
- `extension_score`
- `risk_score`
- `final_score`
- `top_reasons`
- `risk_tags`

说明：

- 不建议只展示一个总分
- 必须保留“可解释性”

## 14. 当前待确认项

当前规则已基本固定，但仍有以下参数可在后续版本中继续调整：

- `板块题材共振` 是否长期采用行业代理口径
- `流通市值弹性` 是否维持 `30亿~150亿` 为最优区间
- `高位连续加速` 的风险阈值是否保持当前设定
