# 次日强势股筛选产品方案

## 1. 文档目的

本文档用于沉淀 `daily_stock_analysis` 中“次日强势股筛选”能力的产品设计，避免后续在新会话或新迭代中丢失上下文。

本文档重点记录：

- 产品目标
- 核心评分逻辑
- 按 Tushare 权限分层的版本规划
- 当前推荐演进路径
- 后续迭代时需要持续维护的决策项

## 2. 产品目标

目标不是评估“今天谁涨得最多”，而是评估：

1. 今日涨幅超过阈值 `N` 的股票中，谁明日更可能继续上涨。
2. 如果继续上涨，谁更可能具备更强的涨幅弹性。
3. 在控制风险的前提下，输出明日最值得关注的 `Top X` 股票。

产品输出应至少包含：

- 候选池筛选结果
- 多维评分结果
- 明日 `Top X`
- 每只股票的加分原因
- 每只股票的主要风险标签

## 3. 产品核心逻辑

产品主流程分为两步：

### 3.1 候选池筛选

先筛选“今天值得进入明日观察池”的股票。

建议默认硬过滤条件：

- 今日涨幅 `>= N`
- 排除 `ST/*ST`
- 排除长期停牌
- 排除上市时间过短的新股
- 默认只看主板
- 设置最低成交额门槛
- 设置最低换手率门槛

### 3.2 多维评分与排序

对候选池做多维评分，得到最终排序。

建议评分结构：

```text
基础总分 = 强势确认质量 + 量价结构 + 趋势位置与形态 + 板块题材共振 + 资金承接质量 + 弹性与股性
最终总分 = 基础总分 - 风险修正
```

建议对外展示 4 个分数：

- `continuation_score`：明日继续上涨概率
- `extension_score`：若上涨，潜在弹性
- `risk_score`：冲高回落、断板、兑现风险
- `final_score`：最终排序分

建议排序公式：

```text
rank_score = continuation_score * 0.65 + extension_score * 0.25 - risk_score * 0.10
```

## 4. 评分维度

当前确定的评分框架如下：

| 维度 | 分值 | 说明 |
|---|---:|---|
| 强势确认质量 | 20 | 判断今天是否“真强”，适配涨停股和非涨停强势股 |
| 量价结构 | 20 | 判断上涨是否有量能支持，且不过热 |
| 趋势位置与形态 | 15 | 判断是启动、主升还是衰竭阶段 |
| 板块题材共振 | 20 | 判断是否处于市场主线和板块前排 |
| 资金承接质量 | 15 | 判断资金质量和承接稳定性 |
| 弹性与股性 | 10 | 判断继续走强后的空间和辨识度 |
| 风险修正 | 0~-20 | 独立扣分项，不混入正向加分 |

### 4.1 强势确认质量

适用于区分“真强”和“假强”。

建议子项：

- 今日涨幅强度
- 收盘位置
- 涨停接近度
- K 线实体强度

### 4.2 量价结构

这是核心维度之一。

建议子项：

- 量比
- 换手率
- 成交额分位
- 放量质量

### 4.3 趋势位置与形态

建议子项：

- 均线结构
- 平台/前高突破结构
- 连续强势状态

### 4.4 板块题材共振

短线次日延续高度依赖该维度。

建议子项：

- 板块涨幅排名
- 板块涨停/大涨家数
- 板块梯队完整度
- 个股板块地位

### 4.5 资金承接质量

建议子项：

- 主力净流入绝对额
- 主力净流入强度
- 龙虎榜质量
- 价资一致性

### 4.6 弹性与股性

建议子项：

- 流通市值弹性
- 历史股性
- 短线辨识度

### 4.7 风险修正

建议风险项：

- 长上影 / 冲高回落
- 爆量滞涨
- 尾盘走弱
- 高位连板过多
- 板块退潮
- 资金背离
- 龙虎榜偏兑现

## 5. 版本规划

本产品按 Tushare 权限与数据能力拆分为三个版本。

---

## 5.1 V1：2000 分版

### 定位

收盘后次日筛选基础版。

### 核心能力

- 今日涨幅阈值筛选
- 收盘后多维评分
- 输出明日 `Top X`

### 适用场景

- 每日收盘后生成次日观察池
- 不依赖盘中实时分时
- 快速落地首版产品

### 主要可用数据

- `daily`
- `stock_basic`
- `daily_basic`
- `moneyflow`
- `top_list`
- `stk_limit`

### 能支撑的评分维度

- 强势确认质量
- 量价结构
- 趋势位置与形态
- 资金承接质量
- 部分板块题材共振
- 部分风险修正

### 局限

- 不能精确判断封板时间
- 不能精确统计开板次数
- 不能精确衡量回封质量
- 不能做真正盘中强弱判断

### 产品结论

`V1` 已经可以形成一个完整可用的“收盘后次日筛选器”，适合作为首版上线能力。

---

## 5.2 V1.5：5000 分版

### 定位

收盘后增强版，正式具备“打板/接力评分”能力。

### 核心能力

- 继承 `V1` 全部能力
- 加入封板质量
- 加入炸板次数
- 加入连板状态
- 加入题材标签
- 加入筹码结构

### 主要新增数据

- `limit_list_d`
- `kpl_list`
- `cyq_perf`
- `cyq_chips`

### 能新增的评分能力

- 首封时间
- 末封时间
- 炸板次数
- 封单金额
- 连板状态
- 开盘啦题材标签
- 筹码成本区
- 获利盘情况
- 筹码集中度

### 产品意义

到 `V1.5`，原始设想中的“打板/接力评分体系”才真正成立。

### 适用场景

- 收盘后强势股接力筛选
- 打板复盘
- 明日接力池生成

### 产品结论

如果产品效果经过 `V1` 验证，`5000` 分是最值得优先升级的一档。

---

## 5.3 V2：5000 分 + 实时分钟

### 定位

完整盘中增强版。

### 核心能力

- 继承 `V1.5` 全部能力
- 加入盘中分时强弱
- 加入封板过程分析
- 加入回封质量分析
- 加入尾盘承接分析

### 主要新增数据

- `rt_min`
- 股票实时日线

说明：

- 实时分钟和实时日线属于独立权限，不是积分自动解锁
- `rt_min` 适合支持盘中分时级增强评分

### 能新增的评分能力

- 实时封板时间判断
- 盘中开板过程追踪
- 回封速度和回封稳定性
- 午后转强/转弱判断
- 尾盘承接和抢跑判断

### 产品意义

`V2` 才是完整的盘中增强版，也是最接近实战交易辅助的版本。

### 适用场景

- 盘中盯盘筛选
- 动态接力池更新
- 午后强弱变化监控

### 产品结论

`V2` 不应作为首版目标，而应建立在 `V1` 和 `V1.5` 已稳定运行的基础上逐步升级。

## 6. 权限与版本映射

| 版本 | 数据能力 | 产品能力 | 推荐程度 |
|---|---|---|---|
| V1 | 2000 分基础权限 | 收盘后次日筛选 | 高 |
| V1.5 | 5000 分 | 收盘后增强打板/接力评分 | 很高 |
| V2 | 5000 分 + 实时分钟 | 盘中增强评分 | 中，按需求升级 |

## 6.1 评分维度与接口映射表

下表用于回答两个问题：

1. 每个评分维度依赖哪些接口。
2. 当前权限下哪些维度可以完整实现，哪些只能部分实现。

| 评分维度 | 关键字段 | 主要接口 | V1 | V1.5 | V2 |
|---|---|---|---|---|---|
| 强势确认质量 | `pct_chg`、`open/high/low/close`、`up_limit` | `daily`、`stk_limit` | 可用 | 可增强 | 完整 |
| 量价结构 | `amount`、`vol`、`turnover_rate`、`volume_ratio` | `daily`、`daily_basic` | 可用 | 可增强 | 完整 |
| 趋势位置与形态 | 均线、阶段高点、连续强势状态 | `daily` | 可用 | 可增强 | 可增强 |
| 板块题材共振 | 板块标签、涨停家数、板块强度、个股地位 | `stock_basic`、`kpl_list`、`limit_cpt_list` | 部分可用 | 明显增强 | 完整 |
| 资金承接质量 | 主力净流入、大单结构、龙虎榜 | `moneyflow`、`top_list` | 可用 | 可增强 | 完整 |
| 弹性与股性 | `circ_mv`、历史强势记录、筹码结构 | `daily_basic`、`daily`、`cyq_perf`、`cyq_chips` | 部分可用 | 明显增强 | 完整 |
| 风险修正 | 长上影、炸板、监管异动、尾盘抢跑 | `daily`、`limit_list_d`、`stk_high_shock`、`rt_min` | 部分可用 | 明显增强 | 完整 |

状态说明：

- `可用`：在该版本下可以支撑核心评分。
- `部分可用`：只能做简化版或代理评分。
- `可增强 / 明显增强`：已有基础能力，但升级后解释力或准确性显著提升。
- `完整`：该版本下可以较完整支撑该维度。

## 6.2 接口分层说明

### V1 核心接口

适用于收盘后基础评分：

- `daily`
- `stock_basic`
- `daily_basic`
- `moneyflow`
- `top_list`
- `stk_limit`

这批接口足以支撑：

- 候选池筛选
- 收盘强度判断
- 量价结构评分
- 资金流向评分
- 基础趋势与风险判断

### V1.5 新增接口

适用于收盘后增强评分：

- `limit_list_d`
- `kpl_list`
- `cyq_perf`
- `cyq_chips`

这批接口主要补齐：

- 封板时间
- 炸板次数
- 封单金额
- 连板状态
- 题材标签
- 筹码结构

### V2 新增接口

适用于盘中增强评分：

- `rt_min`
- 股票实时日线

这批接口主要补齐：

- 分时强弱
- 盘中封板过程
- 回封质量
- 尾盘承接
- 午后强弱切换

## 6.3 各版本新增评分项清单

本节用于后续升级时快速确认“增加权限后，评分系统具体能多做什么”。

### 从 V1 升级到 V1.5

新增推荐评分项：

- 首封时间分
- 末封时间分
- 炸板次数扣分
- 封单强度分
- 连板状态分
- 题材标签加分
- 获利盘结构分
- 筹码集中度分

产品效果变化：

- 从“强势股筛选”升级为“强势股 + 打板/接力评分”
- 对涨停股、准涨停股的区分能力明显增强
- 风险修正会更贴近短线交易实际

### 从 V1.5 升级到 V2

新增推荐评分项：

- 分时转强分
- 回封速度分
- 回封稳定性分
- 午后承接分
- 尾盘抢跑扣分
- 盘中分歧恢复分

产品效果变化：

- 从“收盘后判断”升级为“盘中动态判断”
- 可以支持实时观察池更新
- 可以支持午后临盘优选

## 6.4 版本升级检查清单

每次准备升级版本时，至少核对以下事项：

| 检查项 | V1 | V1.5 | V2 |
|---|---|---|---|
| 当前 Tushare 积分是否满足 | 是 | 是 | 是 |
| 新接口权限是否已实际开通 | 否 | 是 | 是 |
| 新字段是否已稳定可取到 | 否 | 是 | 是 |
| 评分公式是否已更新 | 否 | 是 | 是 |
| 前端展示字段是否同步升级 | 否 | 是 | 是 |
| 风险标签是否同步升级 | 否 | 是 | 是 |

说明：

- `V1` 是基础版本，不需要额外开通增强权限。
- `V1.5` 重点检查打板与筹码相关接口。
- `V2` 重点检查实时分钟与盘中调度能力。

## 7. 当前建议

当前推荐的产品演进顺序：

1. 先用现有 `2000` 分完成 `V1`
2. 验证评分体系有效性后，升级到 `5000` 分做 `V1.5`
3. 若确认需要盘中版，再补实时分钟权限进入 `V2`

不建议直接跳到 `V2`，原因如下：

- 首版产品更需要先验证评分逻辑是否有效
- 只补实时权限但不补 `5000` 分，仍会缺少很多打板核心字段
- `V1.5` 的投入产出比更高

## 8. 版本边界说明

### V1 解决的问题

- 今日强势股筛选
- 收盘后明日候选池排序
- 建立基础评分框架

### V1.5 解决的问题

- 把打板/接力维度真正纳入产品
- 让封板质量和炸板质量进入评分主体系
- 引入筹码结构，提升解释力

### V2 解决的问题

- 把评分从“收盘后判断”升级成“盘中动态判断”
- 提升封板、回封、尾盘承接这类关键实战信号的识别能力

## 9. 后续维护规则

后续每次迭代本产品时，建议同步维护以下内容：

- 当前版本目标是否变化
- 当前评分维度是否变化
- 新增字段来自哪个接口
- 新权限是否已开通
- 评分公式是否调整
- 风险修正规则是否调整

如果评分逻辑发生明显变更，应在本文档末尾追加变更记录。

## 10. 待维护决策项

后续仍需持续确认的关键问题：

- 是否长期坚持主板优先，还是扩展到创业板/科创板
- 板块地位如何定义为统一规则
- 历史股性如何量化
- 风险修正是否引入监管异常波动数据
- 是否将竞价数据纳入 `V2`
