## 2. 背景与结论

当前 `Standard` 与 `Aggressive` 的底层评分规则来自 V1 时代，主要基于：

- `daily`
- `daily_basic`
- `moneyflow`
- `top_list`
- `stk_limit`
- 申万行业 / 旧行业文本代理

Tushare 积分升级到 `6000` 后，评分能力可以升级，但升级方向不是分钟级盘中交易，而是：

```text
真实强板块识别
+ 个股资金承接
+ 涨停 / 炸板结构
+ 开盘啦题材语义
+ 筹码压力
```

结论：

- `Standard` 应优先升级“主线准确性、资金确认、风险过滤”，保持官方主引擎稳健。
- `Aggressive` 应优先升级“强度确认、买入可行性、进攻风险过滤”，保持补充观察定位。
- 两套画像共用同一套 V1.3 数据增强层，但进入评分的权重和用途不同。
- `Aggressive` 仍不得推翻 `Standard` 的今日出手级别、官方 Top3、行动清单和回测主口径。

## 3. 可用数据能力

### 3.1 已可用于评分升级的数据

| 数据能力 | 接口 | 用于 Standard | 用于 Aggressive | 主要用途 |
| --- | --- | --- | --- | --- |
| 东方财富板块行情 | `dc_index` / `dc_concept` | 是 | 是 | 板块涨跌、上涨 / 下跌家数、领涨股、板块宽度 |
| 东方财富板块资金流 | `moneyflow_ind_dc` | 是 | 是 | 板块主力净额、净流入排名、超大单 / 大单结构 |
| 东方财富板块成分 | `dc_member` | 是 | 是 | 股票到真实强板块映射 |
| 开盘啦涨停榜 | `kpl_list` | 辅助 | 重点 | 涨停原因、题材语义、封单、换手、涨停状态 |
| 涨停 / 炸板 | `limit_list_d` | 是 | 重点 | 涨停、炸板、开板次数、连板、封单金额 |
| 个股资金流 | `moneyflow` / `moneyflow_ths` / `moneyflow_dc` | 是 | 重点 | 个股主力承接、大单 / 超大单净流入、5 日资金延续 |
| 筹码分布 | `cyq_perf` / `cyq_chips` | 是 | 是 | 获利盘、成本分位、上方压力、追高风险 |
| 同花顺成分与热榜 | `ths_member` / `ths_hot` / `ths_index` | 辅助 | 辅助 | 成分补充、热度补充、代码翻译 |

### 3.2 仍不可直接用于评分升级的数据

以下能力不属于普通 `6000` 积分下的稳定默认能力，不能作为本阶段评分主依赖：

- 股票实时分钟线。
- 股票历史分钟线。
- 分时均线 / VWAP。
- Level-2 十档盘口。
- 逐笔成交。
- `stk_auction` / `stk_auction_c`，除非额外开通集合竞价或分钟权限。

因此，V1.3 评分升级后仍然必须标注为 `收盘后评分 + 盘中快照辅助`，不得输出分钟级买点已确认。

## 4. Standard 主引擎升级方案

### 4.1 产品定位

`Standard` 是官方主引擎，负责：

- 官方 Top30。
- 二次决策 Top3。
- 今日出手级别。
- 明日行动清单。
- 官方回测主口径。

它的升级目标不是更激进，而是更准确地区分：

```text
真主线强股
vs
孤立强股
vs
后排跟风
vs
追高风险过大的强股
```

### 4.2 维度升级映射

| 现有维度 | 当前口径 | V1.3 升级口径 | 建议处理 |
| --- | --- | --- | --- |
| 强势确认质量 | 涨幅、收盘位置、涨停接近度、K 线实体 | 增加真实涨停 / 炸板 / 连板 / 封单结构 | 小幅增强，不改变主权重 |
| 量价结构 | 量比、换手、成交额分位、价量一致 | 增加 KPL 换手与封单语义，识别一字、换手、分歧回封 | 保持稳健，只做解释和轻量加分 |
| 趋势位置与形态 | 均线、多日涨幅、位置 | 增加筹码获利盘、成本分位和上方压力 | 作为风险过滤主入口 |
| 板块题材共振 | 申万行业 / 候选池行业代理 | 升级为真实强板块：`dc_concept + moneyflow_ind_dc + dc_member` | 重点升级 |
| 资金承接质量 | `moneyflow` 主力净额、龙虎榜 | 增加板块资金流、个股 THS/DC 资金流、5 日资金延续 | 重点升级 |
| 弹性与股性 | 振幅、波动、活跃度 | 保留，避免过度追逐高弹性 | 维持 |
| 风险修正 | 高位、放量、冲高回落等代理 | 增加炸板、开板次数、筹码压力、板块退潮 | 重点升级 |

### 4.3 建议新版维度结构

第一阶段不建议大改总分结构，避免回测不可比。建议在现有 100 分基础内做“替换证据”：

```text
基础总分
= 强势确认质量(20)
+ 量价结构(18)
+ 趋势位置与形态(12)
+ 真实题材共振(25)
+ 资金承接质量(17)
+ 弹性与股性(8)

最终总分 = 基础总分 - 风险修正(0~25)
```

与 V1 相比：

- `板块题材共振` 从 20 提到 25。
- `资金承接质量` 从 15 提到 17。
- `趋势位置与形态` 从 15 降到 12，但筹码压力进入风险修正。
- `风险修正` 上限从 20 提到 25，用来压制炸板、高获利盘和后排跟风。

### 4.4 Standard 新增评分项

#### 4.4.1 真实题材共振 25

| 子项 | 分值 | 数据来源 |
| --- | ---: | --- |
| 父题材强度排名 | 8 | `dc_concept` / `moneyflow_ind_dc` |
| 板块主力净流入 | 6 | `moneyflow_ind_dc` |
| 候选池覆盖密度 | 5 | `dc_member` + 候选池 |
| 板块宽度 | 3 | `dc_index.up_num / down_num` |
| 领涨股 / 代表股一致性 | 3 | `dc_index.leading` + 候选池 |

规则：

- 如果股票属于当天 Top 强板块，且该板块覆盖多只候选股，加分。
- 如果股票只是孤立强股，且不属于任何强板块，降权。
- 如果只拿到同花顺碎片概念，不得直接给满分，必须低置信度。

#### 4.4.2 资金承接质量 17

| 子项 | 分值 | 数据来源 |
| --- | ---: | --- |
| 个股主力净流入绝对额 | 5 | `moneyflow` / `moneyflow_ths` / `moneyflow_dc` |
| 个股主力净流入占比 | 4 | `moneyflow_ths` / `moneyflow_dc` |
| 板块资金共振 | 4 | `moneyflow_ind_dc` |
| 5 日资金延续 | 2 | `moneyflow_ths.net_d5_amount` |
| 龙虎榜 / 异动榜补充 | 2 | `top_list` / `kpl_list` |

规则：

- 个股净流入强，但板块资金弱：只给中等承接分。
- 板块净流入强，但个股净流出：不得给高承接分。
- 个股和板块同时强，才是 Standard 的高确定性资金证据。

#### 4.4.3 风险修正 0~25

| 风险项 | 扣分 | 数据来源 |
| --- | ---: | --- |
| 炸板 / 多次开板 | 0~8 | `limit_list_d` |
| 高获利盘 / 成本偏离过大 | 0~6 | `cyq_perf` / `cyq_chips` |
| 板块资金退潮 | 0~5 | `moneyflow_ind_dc` |
| 后排跟风且非强板块核心 | 0~4 | `dc_member` + 候选池排序 |
| 成交过热 / 冲高回落 | 0~4 | `daily` / `daily_basic` |

规则：

- Standard 应允许强势股正常波动，但要压制“主线不明 + 高获利盘 + 炸板”的组合。
- 风险扣分不得因为单一数据源缺失而误扣；数据缺失时只降低置信度。

## 5. Aggressive 补充引擎升级方案

### 5.1 产品定位

`Aggressive` 只做进攻补充观察，不能产生第二套官方答案。

它的升级目标是识别：

```text
强度更高
+ 更有弹性
+ 仍有参与窗口
+ 不违反 Standard 总闸门纪律
```

### 5.2 维度升级映射

| 现有维度 | 当前口径 | V1.3 升级口径 | 建议处理 |
| --- | --- | --- | --- |
| 强势确认质量 | 涨停接近度、跳空、收盘地位、加速 | 增加真实涨停、封单、开板、回封、连板 | 重点升级 |
| 资金承接质量 | 主力净额、净流入占比、价资一致 | 增加个股 THS/DC 资金流、板块资金共振 | 重点升级 |
| 买入可行性 | 振幅、成交额、追高距离、位置 | 增加 KPL 换手 / 封单 / 状态、炸板回封、筹码压力 | 重点升级 |
| 量价双轨 | 缩量一致 / 健康换手 | 用 KPL 和 limit_list_d 区分一字、换手、分歧回封 | 重点升级 |
| 板块题材共振 | 行业代理 | 真实强板块和父题材归并 | 中等升级 |
| 趋势位置与弹性 | 高位不机械惩罚 | 用筹码压力和炸板风险约束高位弹性 | 风险化处理 |
| 风险修正 | 致命分歧 | 增加炸板、封单弱、筹码压力、板块退潮 | 重点升级 |

### 5.3 建议新版维度结构

Aggressive 可比 Standard 更明显地调整权重：

```text
基础总分
= 强势确认质量(30)
+ 资金承接质量(20)
+ 买入可行性(18)
+ 量价双轨(14)
+ 真实题材共振(10)
+ 趋势位置与弹性(8)

最终总分 = 基础总分 - 风险修正(0~20)
```

与 V1-Aggressive 相比：

- `买入可行性` 从 15 提到 18，因为 KPL / 炸板 / 筹码能更好判断“能不能参与”。
- `板块题材共振` 从 12 降到 10，但从行业代理升级为真实强板块。
- `风险修正` 从 15 提到 20，只惩罚对进攻交易致命的风险。

### 5.4 Aggressive 新增评分项

#### 5.4.1 强势确认质量 30

| 子项 | 分值 | 数据来源 |
| --- | ---: | --- |
| 涨停 / 准涨停强度 | 8 | `stk_limit` / `limit_list_d` |
| 封单与状态 | 7 | `limit_list_d` / `kpl_list` |
| 开板 / 回封结构 | 6 | `limit_list_d` / `kpl_list` |
| 连板 / 高度识别 | 4 | `limit_list_d` |
| 收盘地位与加速 | 5 | `daily` |

规则：

- 封死或强回封可加分。
- 多次炸板但最终弱封，不能只因为涨停接近度高而给满分。
- 一字板强度高但可参与性低，应在买入可行性里被约束。

#### 5.4.1.1 日线封板强度诊断

在当前 V1.3 边界内，不接入分钟线；封板强度只使用 `limit_list_d` 和日线行情可见字段进行诊断。

建议派生字段：

- `first_seal_time`: 来自 `limit_list_d.first_time`
- `seal_amount_ratio`: `limit_list_d.fd_amount / limit_list_d.amount`
- `open_times`: 来自 `limit_list_d.open_times`
- `sealing_strength_score`: `0 ~ 100`
- `sealing_strength_level`: `strong / medium / weak`
- `is_one_word_like`: 由 `open == low == close`、极低换手或 `kpl_list` 一字状态辅助判断

建议评分口径：

| 子项 | 口径 | 处理 |
| --- | --- | --- |
| 首封时间 | `<= 10:00:00` / `10:00 ~ 11:00` / `11:00 ~ 14:00` / `> 14:00` | 由高到低给分，尾盘封板不应被判为高质量封板 |
| 封单强度 | `seal_amount_ratio = fd_amount / amount` | 封单比越高越强，但必须 capped，避免异常封单拉爆分数 |
| 开板稳定性 | `open_times` | `0 ~ 1` 次加分，`>= 3` 次明显扣分 |
| 一字难参与 | `is_one_word_like` | 强度可高，但买入可行性不得因此上调 |

使用边界：

- `sealing_strength_score` 可进入 `强势确认质量` 和二次决策解释层。
- 一字板或极端缩量板只能说明“强封确认”，不能说明“次日好买”。
- 封板强度不得单独覆盖 `buyability_score`、`risk_score` 或总闸门结论。

#### 5.4.2 买入可行性 18

| 子项 | 分值 | 数据来源 |
| --- | ---: | --- |
| 适度换手 / 非一字难买 | 5 | `kpl_list.turnover_rate` / `daily_basic` |
| 分歧转一致结构 | 4 | `limit_list_d.open_times` / `kpl_list.status` |
| 追高空间 | 3 | `stk_limit` / `daily` |
| 筹码压力不过红线 | 3 | `cyq_perf` / `cyq_chips` |
| 成交额可承载 | 3 | `daily` / `daily_basic` |

规则：

- 一字板或极端缩量板可以强，但买入可行性不得给高。
- 换手充分、封板质量可接受、筹码压力不过红线的强票，Aggressive 应优先展示。

#### 5.4.3 风险修正 0~20

| 风险项 | 扣分 | 数据来源 |
| --- | ---: | --- |
| 炸板次数过多 / 弱回封 | 0~6 | `limit_list_d` / `kpl_list` |
| 筹码获利盘过高 | 0~5 | `cyq_perf` |
| 板块资金退潮 | 0~4 | `moneyflow_ind_dc` |
| 高位加速但资金不跟 | 0~4 | `daily` + `moneyflow_ths` |
| 后排补涨且主线过热 | 0~3 | `dc_member` + 主线评分 |

规则：

- Aggressive 不机械惩罚高位，但必须惩罚“高位 + 资金不跟 + 筹码过热”。
- Aggressive 可接受更高波动，但不能接受无买点、无承接、无主线的盲目弹性。

## 6. 两套画像的升级边界

| 问题 | Standard | Aggressive |
| --- | --- | --- |
| 是否改变官方 Top3 | 是 | 否 |
| 是否参与官方回测主口径 | 是 | 否 |
| 是否可影响今日出手级别 | 是 | 否 |
| 是否可以推荐新票 | 是，作为官方组合 | 只作补充观察 |
| 是否允许更高波动 | 中等 | 较高 |
| 是否可绕过买点 | 否 | 否 |
| 是否可绕过 Standard 总闸门 | 不适用 | 否 |

## 7. 数据缺失与降级

所有新数据都必须可降级。

| 缺失数据 | Standard 降级 | Aggressive 降级 |
| --- | --- | --- |
| `dc_concept / dc_index` 缺失 | 回退到 `moneyflow_ind_dc + ths_member` | 回退到 `moneyflow_ind_dc + kpl_list` |
| `moneyflow_ind_dc` 缺失 | 板块资金强度低置信度 | 板块共振降权 |
| `dc_member` 缺失 | 股票到真实板块映射降级 | 题材地位只做辅助 |
| `kpl_list` 缺失 | 不影响基础评分 | 买入可行性低置信度 |
| `limit_list_d` 缺失 | 封板强度低置信度，不硬扣分 | 强势确认与买入可行性低置信度 |
| `moneyflow_ths / moneyflow_dc` 缺失 | 回退 `moneyflow` | 资金承接低置信度 |
| `cyq_perf / cyq_chips` 缺失 | 筹码风险不扣分，只提示缺失 | 买入可行性和风险修正低置信度 |

禁止把数据缺失当作 `0` 分硬扣死。缺失只能降低置信度或回退旧口径。

## 8. 回测验收设计

升级后必须对比以下基准：

1. 旧 Standard vs 新 Standard。
2. 新 Standard 官方 Top3 vs 候选池 Top10。
3. 新 Standard 官方 Top3 vs 原始 rank Top3。
4. Aggressive 补充票 vs Standard 未覆盖票。
5. 强板块覆盖日 vs 主线不清晰日。
6. 筹码 / 炸板风险过滤前后表现。

核心验收指标：

- `短线延续合格率` 是否提升或不下降。
- `T+2 利润窗口` 是否改善。
- `T+2 最大回撤` 是否下降。
- 主仓相对次仓 / 观察仓是否仍有优势。
- Aggressive 补充票是否提供正向增益，而不是制造额外亏损。

## 9. 实施顺序

### 9.1 第一阶段：只增强数据与影子分

- 保持现有 `rank_score` 不变。
- 为候选股追加：
  - `v13_theme_strength_score`
  - `v13_fund_support_score`
  - `v13_limit_structure_score`
  - `v13_buyability_score`
  - `v13_chip_risk_score`
- 页面和回测展示影子分，但不直接改官方排序。

### 9.2 第二阶段：Standard 小权重接入

- 将真实题材共振接入 `sector_resonance`。
- 将板块资金和个股资金共振接入 `capital_support`。
- 将炸板和筹码压力接入 `risk_penalty`。
- 跑 60 交易日严格回测。

### 9.3 第三阶段：Aggressive 重构买入可行性

- 用 `kpl_list + limit_list_d + cyq_perf` 重构 `buyability_score`。
- Aggressive 补充票只保留 `Top2`。
- 统计补充增益率和补充亏损率。

### 9.4 第四阶段：正式替换评分公式

只有当严格回测证明新公式优于旧公式时，才替换生产排序。

## 10. 非目标

- 不接入分钟线。
- 不接入 Level-2。
- 不复刻第三方 App 的专有强度算法。
- 不让 Aggressive 变成第二套官方答案。
- 不因为某个新数据源强就绕过买点和总闸门。

## 11. 一句话版本

V1.3 的 `6000` 积分升级，应让 `Standard` 更会识别“真实主线里的安全强股”，让 `Aggressive` 更会识别“强且还能参与的进攻补充票”，但两者都不能越界成分钟级交易系统。
