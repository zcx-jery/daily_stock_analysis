# 明日观察池摘要 MVP 飞书提交说明

## 1. 适用场景

本说明用于把本次作业提交到飞书表格，字段对应截图中的 3 个输入项：

- 作业简介
- 作业截图
- 程序源文件

## 2. 作业简介可直接粘贴

```text
我这次选择解决的最小痛点是：强势筛选虽然已经能给出 TopN 结果，但收盘后仍然需要手工整理“明日观察池”，包括先看哪几只、题材聚焦在哪、有哪些风险提醒。这个动作每天重复，低效且容易漏看重点。

因此我基于现有 Momentum Screener 做了一个最小 MVP：在筛选结果之上自动生成“明日观察池摘要”，自动输出 Top3 关注标的、进攻首选或低风险优先、题材聚焦、风险提醒和执行建议，并支持一键复制。

整个需求文档先由 Codex 生成，再使用 AI 做检查和优化，重点保证两件事：第一，确实是在解决当前最需要解决的痛点；第二，只做最简单的 MVP 单元，不扩展到新的后端接口、配置项或复杂策略系统。
```

## 3. 作业截图建议

最推荐的截图内容是同一屏里能看见下面这些元素：

- 页面标题“强势筛选”
- 已经执行过一次筛选后的结果状态
- 新增区块“明日观察池摘要”
- Top3 观察标的卡片
- 题材聚焦
- 风险提醒
- `复制观察池摘要` 按钮

### 建议截图步骤

1. 进入 Web 端 `强势筛选` 页面。
2. 点击 `执行筛选`，等待结果出现。
3. 滚动到“明日观察池摘要”区块，让标题、卡片、右侧提示和按钮都出现在同一张截图里。

### 截图判断标准

如果截图里能一眼看出“系统已经自动把筛选结果整理成观察池”，那就是好截图。
