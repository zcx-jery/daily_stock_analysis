# 强势筛选使用说明书（Beta）

本文面向第一次使用 `强势筛选` 的用户。

目标不是教你写代码，而是让你看完后能回答 4 个问题：

1. 这个功能到底是做什么的
2. 参数该怎么设
3. 页面每个窗口在表达什么
4. 每个返回字段到底是什么意思

## 1. 这个功能是做什么的

强势筛选是一个“收盘后选次日观察对象”的工具。

它的基本流程不是“盘中抓瞬时异动”，而是：

1. 用收盘后的日线、成交额、换手率、资金、板块等数据，先从全市场筛出一批强势候选
2. 对候选池做评分和排序
3. 再从完整排序集中做二次决策，收口成：
   - 今天该不该做
   - 哪条主线最强
   - 默认 1-3 票组合
   - 每只票为什么入选/落选
   - 次日该等什么买点

一句话理解：

`强势筛选` 解决的是“收盘后，我明天优先盯哪些强票”；`二次决策` 解决的是“这些票里到底该不该做、先看谁、怎么等买点”。

## 2. 先记住 3 个重要原则

### 2.1 它是 T 日收盘后，为 T+1 做准备

- 今天 4 月 14 日收盘后跑出来的结果，本质上是“给 4 月 15 日盘中参考”的
- 不是让你拿收盘后的静态结果，直接当成今天盘中实时信号

### 2.2 `结果数量` 不等于二次决策的选股范围

当前逻辑是：

`候选池 -> 全量评分排序 -> 二次决策 -> 页面展示 TopN`

也就是说：

- `候选池数量` 是进入评分池的股票数
- `结果数量` 是页面当前显示出来的 TopN
- 二次决策不是只从页面展示的 TopN 里挑票，而是从“完整排序集”里收口

所以你只改 `返回数量`，应该只影响展示和导出，不应该改变主仓 / 次仓 / 观察仓的本质结论。

### 2.3 它给的是“辅助判断”，不是自动下单

页面里的“建议区间”“买点清晰”“建议买/不建议买”，都属于辅助判断。

系统不会替你：

- 自动下单
- 自动分仓
- 自动止损止盈

## 3. 新手怎么开始用

如果你第一次用，建议从下面这套最容易理解的方式开始。

### 3.1 第一步：先选画像

页面左上角有两个画像：

- `Standard`
- `Aggressive`

可以这样记：

| 画像 | 更适合谁 | 核心特点 | 你可以怎么理解 |
| --- | --- | --- | --- |
| `Standard` | 第一次上手、偏稳一点 | 更看重延续性、结构完整度、风险约束 | 先找“更稳的强票” |
| `Aggressive` | 想看更强进攻机会 | 更看重可买性、承接、机会标签 | 先找“更容易形成强买点的票” |

如果你不确定选哪个：

- 第一次先用 `Standard`
- 想看更主动、更激进的观察池，再切 `Aggressive`

### 3.2 第二步：用这套新手默认参数

#### 新手稳一点

- 评分画像：`Standard`
- 返回数量：`30`
- 最小涨幅：`5`
- 最小成交额（亿）：`3`
- 最小换手率（%）：`3`

#### 平衡版

- 评分画像：`Standard`
- 返回数量：`50`
- 最小涨幅：`6`
- 最小成交额（亿）：`3`
- 最小换手率（%）：`3`

#### 激进版

- 评分画像：`Aggressive`
- 返回数量：`20`
- 最小涨幅：`7`
- 最小成交额（亿）：`4`
- 最小换手率（%）：`5`

### 3.3 第三步：按这个顺序读页面

第一次用，不要一上来就盯结果表。

建议按下面顺序看：

1. 看 `今日出手级别`
2. 看 `策略健康`
3. 看 `默认 1-3 票组合`
4. 看 `主线识别`
5. 再看 `筛选结果`
6. 真要盘中执行，再看 `盘中信号`

## 4. 参数是什么意思，怎么设

### 4.1 `评分画像`

可选值：

- `Standard`
- `Aggressive`

含义：

- 决定评分逻辑和排序偏好
- 不同画像下，同一只票的排序分、亮点和优先级可能不同

怎么设：

- 新手先用 `Standard`
- 想更关注强承接、可参与机会，再切 `Aggressive`

### 4.2 `返回数量`

含义：

- 决定页面当前展示多少只结果
- 也影响复制结果、导出 Markdown、导出 CSV 的条数

怎么设：

- 新手建议 `20-50`
- 太小容易只看见很少几只，视角太窄
- 太大容易信息过载

重要提醒：

- 它主要影响展示，不应该改变二次决策本身

### 4.3 `最小涨幅 (%)`

含义：

- 只保留当日涨幅不低于这个阈值的股票

怎么理解：

- 这是“今天至少已经表现出强势”的最低门槛

怎么设：

- 想更广一点：`4-5`
- 想更聚焦强票：`6-8`
- 超过 `9` 时，筛出来通常会更偏极强票或涨停附近个股

### 4.4 `最小成交额 (亿)`

含义：

- 只保留当日成交额不低于这个阈值的股票

怎么理解：

- 成交额太小，往往流动性不足，容易冲得快、回得也快
- 成交额过滤是在排除“太小、太轻、不容易大资金参与”的票

怎么设：

- 新手建议从 `3` 亿开始
- 想看更大资金能参与的票，可以提到 `5-8` 亿

### 4.5 `最小换手率 (%)`

含义：

- 只保留当日换手率不低于这个阈值的股票

怎么理解：

- 换手率太低，往往说明筹码交换不够，参与性弱
- 适当换手代表有博弈、有承接、有确认

怎么设：

- 新手建议 `3-5`
- 偏激进时可以提高到 `5-10`

### 4.6 `交易日`

含义：

- 指定要用哪一天的收盘数据来做筛选

留空时当前逻辑：

- 收盘后优先尝试当天
- 如果当天 EOD 批量数据还没同步完成，会自动回退到上一交易日
- 页面会显示提示文案说明为什么回退

怎么设：

- 平时留空即可
- 只有在你明确想复盘某个历史交易日时，才手动指定日期

### 4.7 当前页面没暴露出来、但系统固定生效的参数

这两个现在属于固定约束：

- `exclude_st = true`
- `main_board_only = true`

含义：

- 默认排除 ST
- 默认只看主板范围

当前 beta 不需要你手动设置。

## 5. 页面每个窗口怎么看

## 5.1 交易日提示条

位置：

- 页面顶部、错误提示下方

它在说什么：

- 当前实际使用的是哪一天的数据
- 如果你手动选了今天，但今天 EOD 数据还没齐，它会明确告诉你“已回退到上一交易日”

你应该怎么用：

- 一旦看到回退提示，先确认这次结果其实是基于哪一天生成的

## 5.2 参数区

位置：

- 左侧 `筛选参数`

它的作用：

- 设置筛选条件
- 记录你上次使用的参数和排序方式

按钮含义：

- `执行筛选`：按当前参数重新跑一次
- `恢复系统默认`：恢复产品默认参数
- `重置`：重置页面参数并立刻重新执行

## 5.3 顶部 4 个摘要卡片

### `候选池数量`

含义：

- 通过硬过滤后，真正进入评分池的股票数

怎么理解：

- 这是“原料池大小”
- 候选池越大，说明今天符合门槛的强票越多

### `结果数量`

含义：

- 当前页面实际显示的 TopN 条数

怎么理解：

- 这是“展示数”，不是“二次决策选股范围”

### `平均排序分`

含义：

- 当前结果列表 `rank_score` 的平均值

怎么理解：

- 可以把它当成“这一屏股票整体强度”的粗略平均值
- 平均越高，通常说明你当前看到的这批票整体更强

### `最高排序分`

含义：

- 当前列表里最高的 `rank_score`
- 副标题会告诉你是哪只票排第 1

怎么理解：

- 用来快速知道今天这一批里最强的是谁

## 5.4 `二次决策`

这是页面里最重要的窗口。

它不是简单重复结果表，而是在回答：

- 今天该不该做
- 做的话先看谁
- 不做的话为什么不做

它主要由下面几块组成。

### A. `今日出手级别`

可选值：

- `强烈可做`
- `可正常出手`
- `谨慎出手`
- `仅观察`
- `今日不做`

怎么理解：

- 这是页面级总判断
- 它看的是“主线强弱 + 默认组合质量 + 策略健康”

你应该怎么用：

- 先看它，再决定后面要不要继续深读
- 如果这里已经是 `今日不做`，后面即使个别票看起来不错，也要非常克制

### B. `策略健康`

含义：

- 它不是在看今天某一只票强不强
- 它是在看：最近一段历史里，这整套筛选 + 二次决策逻辑是不是还有效

主要看两扇窗：

- `20 日当前可用性`
- `60 日结构可信度`

可以这样记：

- `20 日` 更像短期体感，回答“最近还能不能用”
- `60 日` 更像结构稳定性，回答“这套逻辑是不是还值得信”

常见状态：

- `健康`
- `恢复中`
- `失效`

你应该怎么用：

- 如果两扇窗都健康，系统更敢给完整推荐
- 如果一扇窗失效，系统通常会降级
- 如果两扇窗都失效，系统通常会明显劝退

### C. `明日行动清单`

只有当出手级别较高时才会出现。

它按时间拆成 3 段：

- `开盘前`
- `开盘后 30 分钟`
- `开盘后 60 分钟内`

你应该怎么用：

- 把它当成“次日执行顺序表”
- 它不是预测涨跌，而是在告诉你该先盯什么、什么时候收口成买/不买

### D. `默认 1-3 票组合`

三个槽位：

- `主仓`
- `次仓`
- `观察仓`

注意：

- 这里的“主仓/次仓/观察仓”是产品里的优先级称呼
- 不等于系统替你决定真实仓位大小

每张卡主要看这几个字段：

- `买点标签`
  - `买点清晰`
  - `等待触发`
  - `买点不清晰`
- `建议动作`
  - `可准备执行`
  - `继续等触发`
  - `保留观察但不建议执行`
- `主因`
  - 这只票为什么能进组合
- `仓位理由`
  - 它为什么在这个槽位，不在别的槽位
- `执行提示`
  - 次日应该怎么等，不该怎么追
- `优先买入区`
  - 建议重点观察的价格区间

最简单的读法：

- 先看 `主仓`
- 再看 `买点标签`
- 再看 `建议动作`
- 最后看 `执行提示` 和 `优先买入区`

### E. `主线识别`

这里在回答：

- 今天主要强在哪个方向
- 每条主线强度如何
- 每条主线里最值得代表的票是谁

字段含义：

- `主线评分`：这条线综合有多强
- `候选`：这条线里有多少只强势候选
- `清晰`：这条线里有多少只买点清晰
- `龙头`：这条线里有多少只龙头核心

你应该怎么用：

- 先看是不是只有一条主线明显强
- 再看默认组合是不是围绕主线聚焦

### F. `落选说明`

这里不是废话区，而是“为什么没选其他票”的解释区。

常见落选原因包括：

- `非主线 / 主线过弱`
- `主线内名次不够`
- `角色重复`
- `买点不清晰`
- `近期验证偏弱`

你应该怎么用：

- 如果你心里本来更看好某只票，先看它是因为什么被排除
- 这样你能分清：是你看漏了风险，还是系统逻辑需要再调

### G. `证据区`

这里不是给你下结论，而是给你“凭什么这么判断”的证据。

目前主要包括：

- `主线验证`
- `今日结论`
- 其他解释性文案

你应该怎么用：

- 当你不理解为什么系统今天给的是“谨慎出手/今日不做”时，先看这里

## 5.5 `盘中信号`

这部分是给次日盘中用的。

它固定沿用昨晚的：

- 主仓
- 次仓
- 观察仓

不会因为盘中临时波动就把顺序彻底洗掉。

整体字段含义：

- `状态`
  - 例如 `等待开盘`、`继续观察`、`买点已触发`、`不建议执行`
- `置信度`
  - `高置信度 / 中等置信度 / 低置信度`
- `最终结论`
  - `建议买 / 继续观察 / 不建议买`
- `closing_note`
  - 60 分钟收口后的那句总结
- `focus_order`
  - 当前应该先盯哪一只、再盯哪一只

单只票卡片里主要看：

- `statusLabel`：这只票当前是什么状态
- `当前价 / 涨跌幅 / 开盘价`
- `建议区间`
- `price_vs_open_pct`
- `price_vs_entry_high_pct`
- `还差哪些条件`

最简单的读法：

1. 先看整页最终结论是不是 `建议买`
2. 再看主仓有没有 `买点已触发`
3. 如果没有触发，再看“还差哪些条件”
4. 如果出现 `不建议追入`，就不要把冲高当成买点

## 5.6 `明日观察池摘要`

这是把当前结果压缩成一页可复盘、可复制的观察清单。

它更适合：

- 快速回顾
- 分享给别人
- 睡前做第二天盯盘清单

常见内容：

- `优先关注`
- `进攻首选` 或 `低风险优先`
- `题材聚焦`
- `风险提醒`
- `执行建议`

## 5.7 `筛选结果`

这是基础结果表，不是最终执行结论。

它的作用是：

- 让你看完整排序
- 支持重新排序
- 支持点开详情看维度拆解

表头含义如下。

### `排名`

- 当前画像下的名次

### `股票`

- 股票名称 + `ts_code`

### `涨幅`

- 当天涨跌幅

### `排序分`

- 真正用于当前列表排序的分数
- 这是最重要的比较字段

### `延续分`

- 更偏回答“次日是否有继续走强的基础”

### `弹性分`

- 更偏回答“向上扩展空间和股性够不够”

### `风险分`

- 越低越好
- 分数越高，说明这只票越可能存在高位连续加速、价资背离、板块退潮等问题

### `可买分`

- 只对 `Aggressive` 更关键
- 越高，代表越适合作为“可参与机会”来观察

### `板块`

- 当前归属主线/板块

### `地位`

- `龙头 / 前排 / 后排`

## 5.8 个股详情抽屉

你点击结果表任意一行，会打开详情抽屉。

它主要解决两个问题：

1. 这只票到底强在哪
2. 这只票的分是怎么来的

主要内容：

- `最终总分`
- `排序分`
- `延续分`
- `风险分`
- `可买分`、`机会标签`、`建议区间`（更偏 aggressive，当前也可能承接派生区间）
- `亮点标签`
- `风险标签`
- `维度拆解`

`维度拆解` 里每一块会显示：

- 当前维度名称
- `score / maxScore`
- 该维度内部的细项

比如你会看到这些维度名称：

- `强势确认`
- `量价结构`
- `趋势位置`
- `板块共振`
- `资金承接`
- `弹性与股性`
- `买入可行性`
- `量价双轨`
- `趋势位置与弹性`

你不用背公式，只需要记住：

- 哪个维度高，就说明系统认为这只票那方面更强
- 哪个维度弱，就说明它的短板在哪

## 6. 新手最常用的几个判断方法

## 6.1 如果你只想看“今天到底做不做”

只看这 3 个位置：

1. `今日出手级别`
2. `策略健康`
3. `盘中信号 -> 最终结论`

## 6.2 如果你只想看“先盯哪一只”

只看这 3 个位置：

1. `默认 1-3 票组合`
2. `主仓 / 次仓 / 观察仓`
3. `focus_order`

## 6.3 如果你只想看“为什么它会入选”

只看：

- `主因`
- `仓位理由`
- `亮点标签`
- `维度拆解`

## 6.4 如果你只想看“为什么另一只没选上”

只看：

- `落选说明`

## 7. API 返回字段速查

这一节给的是字段字典。

如果你只看页面，可以不用全部记住；但如果你要和产品、开发、测试一起对字段，这一节最有用。

## 7.1 基础筛选响应：`MomentumScreenerResponse`

| 字段 | 含义 | 你应该怎么理解 |
| --- | --- | --- |
| `profile` | 当前画像 | 本次是 `standard` 还是 `aggressive` |
| `trade_date` | 实际用于筛选的交易日 | 真正用来算结果的日期 |
| `requested_trade_date` | 用户请求的日期 | 你手动选了日期时才有值 |
| `trade_date_note` | 交易日说明 | 当天数据未就绪、自动回退等提示 |
| `candidate_count` | 候选池数量 | 通过硬过滤后进入评分池的股票数 |
| `results` | 结果列表 | 当前返回出来的股票数组 |

## 7.2 单只筛选结果：`MomentumScreenerResult`

| 字段 | 含义 | 用户怎么读 |
| --- | --- | --- |
| `rank` | 排名 | 这只票当前在结果里的名次 |
| `ts_code` | 股票代码 | 标准证券代码 |
| `name` | 股票名称 | 股票简称 |
| `pct_chg` | 当日涨幅 | 今天涨了多少 |
| `continuation_score` | 延续分 | 次日继续走强的基础有多强 |
| `extension_score` | 弹性分 | 向上扩展空间和股性强不强 |
| `risk_score` | 风险分 | 越低越好，越高越要谨慎 |

## 8. 最后给新手的使用建议

如果你刚开始用，建议按下面方式理解这套工具：

- 先用 `Standard`
- 先看 `今日出手级别`
- 再看 `策略健康`
- 再看 `主仓 / 次仓 / 观察仓`
- 盘中不要一看到冲高就追，先看 `建议区间` 和 `还差哪些条件`

最重要的一句话是：

不是“筛出来了就买”，而是“筛出来之后，再看主线、策略健康、组合位置和买点是否真正收口”。  
强势筛选帮你缩小范围，二次决策帮你收口判断，盘中信号帮你避免提前下手和追错节奏。
